## 1. 4대 기본 자료형 개요

| 자료형 | 설명 | 예시 | 비고 |
| --- | --- | --- | --- |
| **`int`**<br>

<br>(정수형) | 소수점이 없는 수 | `3`, `0`, `-30` | 0과 음수도 정수에 포함 |
| **`float`**<br>

<br>(실수형) | 소수점이 붙어 있는 수 | `99.9`, `17.2`, `5.0` | **`.0`이 붙으면 무조건 float** |
| **`str`**<br>

<br>(문자열) | 따옴표(`" "` 또는 `' '`)로 감싼 값 | `"센서A"`, `"123"`, `""` | 따옴표 내부의 숫자는 문자열로 인식 |
| **`bool`**<br>

<br>(불리언) | 참/거짓을 나타내는 값 | `True`, `False` | **첫 글자는 반드시 대문자** |

### 📌 따옴표 활용 팁 (`str`)

문자열 내부에 따옴표가 들어가야 할 때는 감싸는 따옴표를 다르게 지정합니다.

```python
illit = "It's me"  # 바깥을 큰따옴표("")로 감싸서 내부의 작은따옴표(') 보호

```

## 2. 자료형 확인: `type()` 함수

* **`type(확인할값)`**: 전달된 값의 자료형(Class)을 반환합니다.
* 터미널에 결과를 보려면 반드시 `print()`로 감싸야 합니다.

```python
num = 123
print(type(num))       # <class 'int'>
print(type("센서A"))   # <class 'str'>
print(type(True))      # <class 'bool'>

```

### 🔍 평가 순서(Evaluation Flow) 이해하기

`print(type(3 > 2))` 코드가 실행되는 과정:

```text
1. 3 > 2 연산 실행        ➔ 결과: True
2. type(True) 실행       ➔ 결과: <class 'bool'>
3. print(<class 'bool'>)  ➔ 터미널 출력

```

## 3. 실수 연산 오차와 `round()` 함수

### 📌 컴퓨터의 부동소수점(Floating Point) 오차

컴퓨터는 이진법(0과 1)으로 소수를 계산하기 때문에 소수 연산 시 미세한 오차가 발생할 수 있습니다.

```python
print(0.1 + 0.2)  # 0.30000000000000004 (오차 발생)

```

### 📌 해결책: `round(값, 소수자릿수)`

소수점을 반올림하여 깔끔한 수치로 변환해 줍니다.

* `round(값)`: 소수점 첫째 자리에서 반올림하여 **정수** 반환
* `round(값, N)`: **소수 N번째 자리까지** 남기도록 반올림

```python
print(round(0.1 + 0.2))        # 0
print(round(0.1 + 0.823, 2))  # 0.92 (소수 둘째 자리까지 반올림)

```

## 4. 자료형에 따른 연산 동작 차이

같은 연산자(`+`)라도 자료형에 따라 전혀 다르게 동작합니다.

```python
# int + int ➔ 산술 덧셈
print(3 + 5)      # 8

# str + str ➔ 문자열 이어 붙이기
print("3" + "5")  # 35

```

## ⚠️ 자주 하는 실수 & 핵심 주의사항

| 실수 유형 | 예시 코드 | 결과 및 이유 |
| --- | --- | --- |
| **서로 다른 타입의 `+` 연산** | `print("123" + 456)` | ❌ **`TypeError`** (문자열과 숫자는 연결/더하기 불가) |
| **나눗셈의 결과 타입** | `print(10 / 2)` | ⚠️ **`5.0` (`float`)** (딱 떨어지는 나누기도 무조건 실수 반환) |
| **`bool` 작성 대소문자** | `ok = true` | ❌ **`NameError`** (첫 글자는 대문자 `True`, `False` 필수) |
| **변수명 오용** | `str = "문자열"` | ⚠️ 파이썬 내장 키워드인 `str`을 변수명으로 쓰면 기존 `str()` 함수 사용 시 충돌 위험 |

## ⚠️ 자료형 다룰 때 자주 하는 실수 요약

| 구분 | 오류 예시 | 원인 및 해결 방법 |
| :--- | :--- | :--- |
| **자료형 혼용 연산** | `print("100" + 20)` | **`TypeError` 발생!**<br>문자열과 숫자는 `+`할 수 없으므로 `str(20)`으로 형변환하거나 `,`(쉼표) 사용 |
| **`bool` 대소문자 오타** | `is_ok = true` | **`NameError` 발생!**<br>첫 글자를 대문자인 `True` / `False`로 작성 |
| **숫자 모양 문자열** | `a = "10"`<br>`b = "20"`<br>`print(a + b)` | `30`이 아니라 `"1020"` 출력!<br>연산이 필요하면 따옴표를 빼거나 `int()` 사용 |
| **나눗셈 연산의 타입** | `print(type(10 / 2))` | 정수로 나누어 떨어져도 나눗셈(`/`)의 결과는 무조건 **`<class 'float'>`** |
---

Here's my take: 형변환(Type Casting)은 서로 다른 자료형끼리 값을 맞춰주거나, 입력받은 데이터를 원하는 형태로 가공할 때 사용하는 파이썬의 필수 도구입니다.

자주 사용하는 4가지 핵심 형변환 함수인 `int()`, `float()`, `str()`, `bool()`의 동작 방식과 실전 활용 예시를 정리해 드릴게요.

---

## 1. `int()` — 정수형으로 변환

실수(float)나 숫자 형태의 문자열(str)을 정수(int)로 바꿉니다.

* **동작 방식**:
* **실수 ➔ 정수**: 소수점 아래 자리를 버립니다(내림 처리).
* **문자열 ➔ 정수**: `"10"`처럼 정수로 변환 가능한 문자열만 가능하며, `"10.5"`나 `"abc"`처럼 소수점/문자가 섞인 문자열은 `ValueError`가 발생합니다.



```python
# 1. 실수를 정수로 (소수점 이하 절삭)
print(int(3.99))       # 3

# 2. 숫자 문자열을 정수로
print(int("100"))      # 100

# ❌ 오류 케이스
# print(int("3.14"))   # ValueError! (소수점이 포함된 문자열은 int()로 바로 바꿀 수 없음)

```

---

## 2. `float()` — 실수형으로 변환

정수(int)나 실수 형태의 문자열(str)을 소수점이 있는 실수(float)로 바꿉니다.

* **동작 방식**:
* **정수 ➔ 실수**: 값 뒤에 `.0`을 붙여 실수로 만듭니다.
* **문자열 ➔ 실수**: `"10"`, `"3.14"` 모두 실수 형태로 변환해 줍니다.



```python
# 1. 정수를 실수로
print(float(5))        # 5.0

# 2. 문자열을 실수로
print(float("3.14"))   # 3.14
print(float("10"))     # 10.0

```

> 💡 **꿀팁**: `"3.14"` 같은 실수 모양 문자열을 정수로 바꾸고 싶다면, `int(float("3.14"))` 처럼 **`float`을 먼저 거친 후 `int`로 변환**하면 오류 없이 `3`을 얻을 수 있습니다.

---

## 3. `str()` — 문자열로 변환

숫자, 불리언 등 어떤 자료형이든 따옴표로 감싸진 문자열(str)로 변환합니다.

* **동작 방식**: 파이썬의 거의 모든 객체를 텍스트 형태로 바꿉니다.
* **주요 활용**: `print()`문에서 문자열과 숫자를 `+` 연산자로 연결할 때 필수적으로 사용됩니다.

```python
temp = 25

# 숫자와 문자열을 '+'로 그냥 더하면 TypeError 발생!
# print("현재 온도는 " + temp + "도입니다.") # ❌ 오류

# str()로 변환하여 문자를 이어 붙임
print("현재 온도는 " + str(temp) + "도입니다.") # ⭕ 현재 온도는 25도입니다.

```

---

## 4. `bool()` — 불리언(참/거짓)으로 변환

어떤 값이 **비어있거나 0인지(False)**, 아니면 값이 존재하는지(True)를 판별하여 `True` 또는 `False`로 변환합니다.

* **False가 되는 값 (Truthy / Falsy 개념)**:
* 숫자 `0`, `0.0`
* 빈 문자열 `""`
* 빈 리스트 `[]`, 빈 튜플 `()`, 빈 딕셔너리 `{}`
* `None` (값이 없음)


* **True가 되는 값**:
* `0`이 아닌 모든 숫자 (`1`, `-5`, `0.1` 등)
* 글자가 하나라도 들어있는 문자열 (`" "`, `"0"`, `"False"` 등)
* 요소가 들어있는 리스트, 튜플 등



```python
# Falsy (거짓으로 평가되는 값들)
print(bool(0))        # False
print(bool(""))       # False (빈 문자열)
print(bool([]))       # False (빈 리스트)

# Truthy (참으로 평가되는 값들)
print(bool(100))      # True
print(bool("안녕"))   # True
print(bool(" "))      # True (공백도 문자로 취급!)
print(bool("0"))      # True (문자열 '0'은 비어있지 않으므로 True)

```

## 💡 형변환 실전 활용 예시

### ① 사용자 입력(`input()`) 처리할 때

`input()` 함수로 입력받은 값은 무조건 문자열(str)입니다. 따라서 계산을 하려면 반드시 `int()`나 `float()`로 형변환을 해주어야 합니다.

```python
# input()은 문자열로 들어옴
age = input("나이를 입력하세요: ") # 예: "20" 입력

# 형변환 없이 계산 시 오류 또는 원하지 않는 결과 발생!
# next_age = age + 1  # ❌ TypeError!

next_age = int(age) + 1  # ⭕ 정수로 변환 후 계산
print(f"내년 나이: {next_age}세")

```

---

### ② 데이터가 비어있는지 확인할 때

`bool()`의 특성을 활용하면 리스트나 문자열에 값이 들어있는지 간편하게 체크할 수 있습니다.

```python
user_name = ""  # 입력값이 없는 상태

if not bool(user_name): # user_name이 비어있으면 bool() 결과가 False
    print("이름을 입력해 주세요!")

```
