표현식, 식별자, 키워드, 연산자 등 기본요소 ➡️ 문장 ➡️ 프로그램

## 1. 문장
실행할 수 있는 최소 단위를 문장이라 함

문장들이 모여 프로그램이 됨

## 2. 표현식
파이썬에서 어떠한 값을 만들어 내는 간단한 코드를 표현식이라 함

- 숫자, 수식, 문자열 등
- 어떠한 값을 만들어 낼 수 없으면 표현식이라고 할 수 없음.

## 3. 키워드
키워드는 특별한 의미가 부여된 단어로 파이썬이 만들어질 때 이미 사용하겠다고 설정해 놓은 것.

사용자가 키워드인지 아닌지 구분해야하는 이유는 프로그래밍 언어에서 사용자가 이름을 정할 때 키워드를 사용하면 안되기 때문

---

### 1. 불리언 및 값 (Boolean & Values)

| 키워드 | 설명 |
| --- | --- |
| `True` | 참(True)을 나타내는 불리언 값 |
| `False` | 거짓(False)을 나타내는 불리언 값 |
| `None` | 값이 없음(Null)을 나타내는 특수 상수 |

### 2. 제어 흐름 및 반복문 (Control Flow)

| 키워드 | 설명 |
| --- | --- |
| `if` | 조건문 시작 |
| `elif` | 이전 조건이 거짓일 때 검사할 추가 조건 |
| `else` | 모든 조건이 거짓일 때 실행할 블록 |
| `for` | 시퀀스(리스트, 튜플 등)를 순회하는 반복문 |
| `while` | 조건이 참인 동안 반복 실행하는 문 |
| `break` | 가장 가까운 반복문을 즉시 종료 |
| `continue` | 현재 반복을 건너뛰고 다음 반복으로 이동 |
| `pass` | 아무 작업도 하지 않는 빈 실행 블록 생성 |
| `match` | 구조적 패턴 매칭 시작 (Python 3.10+) |
| `case` | `match` 문 내부의 패턴 비교 케이스 지정 |

### 3. 논리 및 연산자 (Logic & Operators)

| 키워드 | 설명 |
| --- | --- |
| `and` | 논리 AND 연산자 (둘 다 참일 때 `True`) |
| `or` | 논리 OR 연산자 (하나라도 참이면 `True`) |
| `not` | 논리 NOT 연산자 (참/거짓 반전) |
| `is` | 두 변수가 동일한 메모리 객체를 가리키는지 확인 |
| `in` | 특정 값이 시퀀스 내에 존재하는지 확인 |

### 4. 함수 및 클래스 (Functions & Classes)

| 키워드 | 설명 |
| --- | --- |
| `def` | 함수 정의 |
| `return` | 함수의 실행을 종료하고 결과값을 반환 |
| `lambda` | 익명(한 줄) 함수 생성 |
| `yield` | 제너레이터 함수에서 값을 생성하고 일시 중지 |
| `class` | 클래스 정의 |

### 5. 예외 처리 (Exception Handling)

| 키워드 | 설명 |
| --- | --- |
| `try` | 예외 발생 가능성이 있는 코드 블록 시작 |
| `except` | 발생한 예외를 포착하여 처리하는 블록 |
| `finally` | 예외 발생 여부와 상관없이 항상 실행되는 블록 |
| `raise` | 의도적으로 예외를 발생시킴 |
| `assert` | 디버깅용 단언문 (조건이 거짓이면 `AssertionError` 발생) |

### 6. 변수 범위 및 메모리 (Variables & Scope)

| 키워드 | 설명 |
| --- | --- |
| `global` | 전역 변수를 함수 내부에서 수정할 때 사용 |
| `nonlocal` | 중첩 함수에서 상위(중첩) 영역의 변수를 수정할 때 사용 |
| `del` | 변수, 리스트 요소 또는 객체 속성을 삭제 |

### 7. 모듈 및 문맥 관리 (Modules & Context)

| 키워드 | 설명 |
| --- | --- |
| `import` | 외부 모듈이나 패키지를 불러옴 |
| `from` | 모듈 내부의 특정 클래스, 함수, 변수만 지정하여 불러옴 |
| `as` | 불러온 모듈이나 예외, context 객체에 별칭 부여 |
| `with` | 자원의 할당과 해제를 자동으로 관리 (Context Manager) |

### 8. 비동기 프로그래밍 (Async Programming)

| 키워드 | 설명 |
| --- | --- |
| `async` | 비동기 함수(코루틴) 또는 비동기 구문 정의 |
| `await` | 비동기 작업이 완료될 때까지 일시 대기 |


## 3. 식별자 (identifier)
식별자는 프로그래밍 언어에서 이름을 붙일 때 사용하는 단어.

< 반드시 지켜야흘 식별 규칙 >

- 키워드 사용 금지
- 특수 문자는 _ 만 허용
- 숫자로 시작 금지
- 공백 포함 안됨


* 스네이크 케이스 (snake_case)

- 특징 : 소문자로 시작, 스네이크 케이스 뒤에 (괄호 있으면) 함수 / (괄호 없으면) 변수

itemlist -> item_list 이처럼 표기하는 것을 말함



* 캐멀 케이스 (CamelCase)

- 특징 : 대문자로 시작하며 캐멀 케이스로 작성되어 있으면 클래스

itemlist -> ItemList 이처럼 표기하는 것
