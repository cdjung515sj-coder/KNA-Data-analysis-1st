## 1. 기본 산술 연산자 종류

파이썬에는 총 6가지의 대표적인 산술 연산자가 있습니다.

| 연산자 | 기능 | 예시 | 결과 | 비고 |
| --- | --- | --- | --- | --- |
| **`+`** | 더하기 | `7 + 14` | `21` | 문자열 이어붙이기 연산으로도 사용됨 |
| **`-`** | 빼기 | `7 - 14` | `-7` | 음수 결과도 정상적으로 처리 |
| **`*`** | 곱하기 | `7 * 14` | `98` | 문자열 반복 연산으로도 사용됨 |
| **`/`** | 나누기 | `7 / 14` | `0.5` | **결과는 항상 실수(`float`)로 반환됨** |
| **`//`** | 몫 (정수 나누기) | `7 // 2` | `3` | 나눈 결과에서 소수점을 버리고 **몫(정수)**만 남김 |
| **`%`** | 나머지 | `7 % 2` | `1` | 나눈 후 **남은 나머지**를 구함 (짝수/홀수 판별 시 유용) |

```python
# 몫과 나머지 연산 예시
print(7 // 2)  # 3 (몫)
print(7 % 2)   # 1 (나머지)

```

## 2. 연산자 우선순위와 괄호 `()`

수학에서와 마찬가지로 파이썬 연산자도 우선순위가 있습니다.

* **우선순위**: `*`, `/`, `//`, `%` 가 `+`, `-` 보다 우선하여 먼저 계산됩니다.
* **우선순위 변경**: `+` 나 `-` 를 먼저 계산하고 싶다면 **괄호 `()**` 를 사용합니다.

```python
print(75 + 80 / 2)    # 115.0  -> (80 / 2 = 40.0) 계산 후 75를 더함
print((75 + 80) / 2)  # 77.5   -> (75 + 80 = 155) 계산 후 2로 나눔

```

## 3. 절댓값 함수 `abs()`

작성하신 코드 중 `abs(Temperature_1st - Temperature_2nd)` 에 사용된 `abs()` 함수입니다.

* **`abs()` (Absolute Value)**: 음수를 양수로 바꾸어 주는 **내장 함수**입니다.
* **사용 목적**: 차이(변화량)를 구할 때 어느 값이 더 큰지 일일이 비교하지 않고, 항상 양수의 "거리/차이값"만 구하고 싶을 때 유용합니다.

```python
print(abs(75 - 80))  # -5 의 절댓값인 5 가 출력됨

```

## 4. 💡 추가로 알아두면 좋은 보완 개념 (중요!)

### ① 일반 나누기(`/`)는 항상 실수(`float`)를 반환합니다.

정수끼리 나누더라도 일반 나누기(`/`)를 사용하면 파이썬은 **결과를 소수점이 있는 실수 타입**으로 바꿉니다.

```python
print(10 / 2)        # 5 가 아니라 5.0 (float)으로 출력됨
print(type(10 / 2))  # <class 'float'>

```

> **왜 그럴까요?**
> 파이썬 3에서는 나눗셈의 정확도를 유지하기 위해 결과값을 무조건 실수 타입으로 변환하도록 설계되어 있습니다.

### ② 몫 연산자(`//`)와 나머지 연산자(`%`)의 활용법

이 두 연산자는 프로그래밍에서 매우 자주 쓰입니다.

* **홀수 / 짝수 구분하기**: `숫자 % 2`의 결과가 `0`이면 짝수, `1`이면 홀수
* **주기적 반복 제어**: `시간 % 12` (12시간 단위 시계), `일자 % 7` (요일 계산)
* **단위 변환**: `초(second)`를 `분(minute)`과 `초`로 나눌 때
```python
total_seconds = 135
minutes = total_seconds // 60  # 2 분 (몫)
seconds = total_seconds % 60   # 15 초 (나머지)
print(f"{minutes}분 {seconds}초")  # 2분 15초

```

## 5. ⌨️ 개발 생산성을 높이는 단축키 & 에러 해결 팁

| 단축키 | 기능 | 비고 |
| --- | --- | --- |

### 📌 에러(Error)를 다루는 바람직한 태도

> *"오류 메시지는 컴퓨터가 나를 공격하는 게 아니라, **어디가 왜 아픈지 알려주는 친절한 설명서**입니다."*

1. **에러 메시지의 맨 아랫줄 확인**: 보통 에러의 핵심 이유(`SyntaxError`, `TypeError`, `NameError` 등)가 나와 있습니다.
2. **에러 메시지 복사 후 구글링**: 에러 메시지 그대로 복사해서 검색창에 넣으면 99%의 해결 방법을 찾을 수 있습니다.
3. **주석 활용**: 코드가 동작하지 않을 때, 에러가 의심되는 줄을 `Ctrl + /` 로 잠깐 주석 처리해 가며 범위를 narrowing(축소)하는 습관이 좋습니다.
