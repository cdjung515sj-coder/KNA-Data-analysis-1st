## 1. `print()` 함수의 기본 사용법

* **내장 함수(Built-in Function)**: 파이썬 설치 시 기본으로 제공되므로 별도의 설치나 불러오기 없이 바로 사용 가능합니다.
* **기본 동작**: 괄호 `()` 안에 전달된 값을 화면(터미널)에 출력하며, **기본적으로 출력 후 다음 줄로 자동으로 줄바꿈**합니다.

```python
print("Hello")   # Hello 출력
print(714)       # 714 출력

# 각각 한 줄씩 출력됨
print("첫 번째 줄")
print("두 번째 줄")

```

## 2. 숫자 vs 문자열의 차이

### 📌 문자열(String)

* 큰따옴표(`" "`) 또는 작은따옴표(`' '`)로 감싸서 표현합니다.
* ⚠️ **주의**: 따옴표를 쓸 때는 시작과 끝의 모양을 맞춰야 합니다. (`" '`와 같은 혼용 불가)

### 📌 숫자(Number)

* 따옴표 없이 입력하며, 정수(`int`)와 소수점이 있는 실수(`float`) 모두 그대로 출력 가능합니다.

```python
print(1133)   # 정수 출력
print(3.14)   # 실수 출력

# 따옴표 유무에 따른 차이
print(1)     # 숫자 1
print("1")   # 문자열 "1"

```

### 📌 숫자와 문자열의 연산 차이

| 연산자 | 숫자 연산 (`123 + 456`) | 문자열 연산 (`"123" + "456"`) |
| --- | --- | --- |
| **`+` (더하기)** | **산술 덧셈**: `579` | **글자 이어 붙이기**: `123456` |
| **`*` (곱하기)** | **산술 곱셈**: `5 * 2 = 10` | **글자 반복하기**: `"5" * 4 = 5555` |

## 3. f-string (포맷 문자열) 이해하기

코드 중 작성하셨던 **`print(f"...")`** 형태에 대한 설명입니다.

* **f-string이란?**: 문자열 앞에 알파벳 `f`를 붙이고, 문자열 내부의 중괄호 `{}` 안에 **변수나 식**을 집어넣어 **문자열 속에 값을 간편하게 삽입**하는 기능입니다.
* **사용 이유**: `,`나 `+`를 복잡하게 쓰지 않고도 깔끔한 문장을 만들 수 있습니다.

```python
date_num = 20260714
date_str = "2026년 07월 14일"

# 중괄호 {} 안에 변수나 계산식을 넣어서 출력
print(f"오늘 날짜 숫자로 출력: > {date_num}")
print(f"오늘 날짜 문자로 출력: > {date_str}")

```

> ⚠️ **f-string 따옴표 작성 팁**: `f"{ "2026년" }"`처럼 f-string 전체를 감싼 따옴표와 `{}` 안에서 쓰는 따옴표의 종류가 같으면 문법 에러가 발생할 수 있으니 주의해야 합니다. (바깥이 `"`면 안쪽은 `'` 사용)

## 4. 여러 값 출력하기 (쉼표 `,` vs 더하기 `+`)

### 📌 쉼표 (`,`) 구분 출력

* 여러 값을 **서로 다른 자료형이라도 한 번에 출력**할 수 있습니다.
* ⭐ **특징**: 값과 값 사이에 **자동으로 공백(띄어쓰기 1칸)이 삽입**됩니다.

```python
print("온도(℃):", 75, "도")  # 출력: 온도(℃): 75 도

```

### 📌 더하기 (`+`) 연산자 출력

* 문자열과 문자열을 **공백 없이 바짝 붙여서** 출력합니다.
* ⚠️ **제약사항**: **문자열끼리만 연결 가능**합니다. (문자열 + 숫자는 에러 발생)

```python
print("온도(℃ ):" + "75")    # 출력: 온도(℃ ):75 (띄어쓰기 없음)

```

## 5. 변수(Variable)와 출력

* 데이터에 **이름표**를 붙여 저장해 두는 공간입니다.
* 변수를 만들지 않고 출력하려고 하면 파이썬이 찾지 못해 에러가 발생합니다.

```python
temperature = 75
vibration = 2.3

# 변수에 저장된 값이 들어감
print("온도(℃):", temperature)  # 출력: 온도(℃): 75
print("진동(mm/s):", vibration)  # 출력: 진동(mm/s): 2.3

```

## 6. ⚠️ 핵심 주의사항 요약

| 원인 | 발생 예시 | 해결 방법 |
| --- | --- | --- |
| **대소문자 오타** | `Print("Hello")` | 파이썬은 대소문자를 구분하므로 소문자 `print()`로 작성 |
| **0으로 시작하는 숫자** | `print(0123)` | 숫자를 `0`으로 시작하면 **8진수 인식 오류** 발생 ➔ `"0123"` 문자열로 작성 |
| **선언되지 않은 변수** | `print(Hello)` | `NameError` 발생 ➔ 따옴표를 붙여 문자열로 만들거나 변수를 먼저 정의 |
| **자료형 혼용 `+` 연산** | `print("온도: " + 75)` | `TypeError` 발생 ➔ 쉼표 `,`를 사용하거나 `f"온도: {75}"` 활용 |
