## 1. 변수의 개념과 선언 방법

* **변수(Variable)**: 데이터를 저장해 두는 메모리 공간의 **이름표**입니다.
* **선언 규칙**: `변수이름 = 저장할값`
* 숫자는 따옴표 없이, 문자열은 반드시 따옴표(`" "` 또는 `' '`)로 감싸서 저장합니다.
* 따옴표로 감싸면 **문자열**, 따옴표가 없으면 **변수 이름 또는 숫자**로 인식합니다.



```python
temp = 36       # 숫자 36 저장
name = "센서 A"  # 문자열 저장

print(temp)     # 36 (변수 temp에 저장된 값 출력)
print("temp")   # temp (문자열 그대로 출력)

```

## 2. 할당 연산자(`=`)와 자기 자신을 이용한 재할당

* **`=` (할당 연산자)**: 수학의 "같다"가 아니라, "오른쪽의 계산 결과를 왼쪽 변수에 저장한다"는 의미입니다.
* *참고*: 수학의 "같다"는 파이썬에서 `==` (비교 연산자)를 사용합니다.


* **오른쪽 먼 계산 원칙**: `x = x + 5`와 같은 코드는 **오른쪽 `x + 5`를 먼저 계산**한 후, 그 결과를 다시 `x`에 덮어씌웁니다.

```python
x = 5
x = x + 5  # (1) 기존 x(5) + 5 = 10 을 계산  (2) x에 10을 재할당
print(x)   # 10

```

## 3. 변수의 재할당과 흐름 추적

* 파이썬 코드는 **위에서 아래로 순차적으로 실행**됩니다.
* 변수를 호출할 때는 **가장 최근(마지막)에 저장된 값**을 가져옵니다.
* **대소문자를 엄격히 구분**합니다. (`temp`와 `Temp`는 완전히 다른 변수)

```python
score = 10
score = 20
score = 30  # 가장 마지막에 저장된 값
print(score) # 30 출력

temp = 36
Temp = 150  # 대소문자가 다르므로 별개의 변수로 생성됨

```

## 4. 값 복사의 원리 (기본 자료형)

`b = a` 코드는 "a의 메모리 주소나 연결고리"를 지속하는 것이 아니라, **`b = a`가 실행되는 그 순간의 a 값을 복사**해서 `b`에 넣는 것입니다.

```python
a = 10
b = a     # 이 순간의 a 값(10)이 b에 복사됨 (b = 10)
a = 100   # a의 값을 100으로 바꿔도

print(a)  # 100
print(b)  # 10 (b의 값은 그대로 10 유지!)

```

## 5. 다중 할당 (여러 변수 한 번에 선언)

* 쉼표(`,`)를 이용해 한 줄에서 여러 변수에 값을 동시에 할당할 수 있습니다.
* ⚠️ **주의**: **왼쪽 변수의 개수**와 **오른쪽 값의 개수**가 반드시 일치해야 합니다.

```python
# ⭕ 정상 동작 (변수 2개, 값 2개)
width, height = 10, 20
print(width, height)  # 10 20

# ❌ ValueError 발생 (변수 3개, 값 2개)
# x, y, z = 10, 20

```

## 6. 파이썬 변수명 명명 규칙 (Naming Convention)

코드는 작성하는 시간보다 **남(또는 미래의 나)이 읽는 시간이 훨씬 깁니다.** 따라서 직관적이고 규칙에 맞는 이름을 짓는 것이 중요합니다.

### 📌 필수 규칙 (위반 시 SyntaxError)

1. **숫자로 시작할 수 없음** (`1st_temp` ❌ ➔ `temp_1st` ⭕)
2. **공백(띄어쓰기) 포함 불가** (`device temp` ❌ ➔ `device_temp` ⭕)
3. **특수문자는 언더바(`_`)만 허용**
4. **파이썬 예약어(키워드) 사용 불가** (`if`, `for`, `def`, `class` 등)

### 📌 권장 스타일 (스네이크 케이스: Snake Case)

* 소문자로 작성하되, 단어와 단어 사이는 언더바(`_`)로 연결합니다.
* 의미를 알 수 없는 한 글자 변수(`a`, `b`)보다 **직관적인 이름**을 사용합니다.

```python
# ❌ 좋지 않은 예
a = 25
b = 3

# ⭕ 바람직한 예 (스네이크 케이스)
device_temp = 25   # 장비 온도
sensor_count = 3  # 센서 개수

```
