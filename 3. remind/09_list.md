## 1. 리스트의 기본 개념

* **정의**: 여러 개의 값을 `[]`(대괄호)로 감싸서 **순서대로** 저장하는 파이썬의 대표적인 자료형입니다.
* **특징**:
* 서로 다른 자료형(숫자, 문자열, 불리언 등)을 **한 리스트에 함께 저장**할 수 있습니다.
* 요소의 개수는 `len()` 내장 함수로 확인할 수 있습니다.



```python
int_temps = [10, 20, 30, 40, 50, 60, 100]   # 정수 리스트
mixed = ["펌프", 78, True]                   # 여러 자료형 혼합 리스트
empty = []                                 # 빈 리스트

print(len(int_temps))  # 출력: 7
print(type(mixed))     # 출력: <class 'list'>
print(type(mixed[0]))  # 출력: <class 'str'>

```

## 2. 인덱싱과 슬라이싱

### 📌 인덱싱 (Indexing)

* **`리스트[인덱스]`**: 특정 위치의 단일 요소를 추출합니다.
* **음수 인덱스 (`-1`)**: 뒤에서부터 접근할 때 사용하며, **가장 마지막 요소를 가져올 때 가장 유용**합니다.
* ⚠️ **수정 가능**: 문자열과 달리 **리스트는 인덱스를 이용해 직접 값을 변경**할 수 있습니다.

```python
print(int_temps[0])   # 10 (첫 번째 요소)
print(int_temps[-1])  # 100 (마지막 요소)

# 값 변경
int_temps[2] = 999
print(int_temps)      # [10, 20, 999, 40, 50, 60, 100]

```

### 📌 슬라이싱 (Slicing)

* **`리스트[시작:끝:간격]`**: 특정 범위를 잘라내어 **새로운 리스트**로 반환합니다.

| 구분 | 인덱싱 (`[]`) | 슬라이싱 (`[:]`) |
| --- | --- | --- |
| **반환 형태** | 값 (Element) | **리스트 (List)** |
| **범위 벗어남** | ❌ **`IndexError` 발생** | ⭕ **에러 없음** (있는 만큼만 반환) |

```python
print(int_temps[1:3])    # [20, 999] (1번부터 2번까지)
print(int_temps[100:999]) # [] (범위를 벗어나도 에러 없이 빈 리스트 반환)

```

## 3. 값 존재 여부 및 위치 확인

* **`in` / `not in**`: 해당 값이 리스트 안에 포함되어 있는지 연산하여 `True`/`False`를 반환합니다.
* **`.index(값)`**: 찾으려는 값의 인덱스 번호를 반환합니다.
* ⭐ **중요**: 동일한 값이 여러 개 있어도 **가장 먼저 발견된 첫 번째 인덱스만 반환**합니다.



```python
str_machines = ["펌프", "압축기", "모터", "압축기"]

print("펌프" in str_machines)      # True
print(str_machines.index("압축기")) # 1 (중복이 있어도 가장 앞의 인덱스 반환)

```

## 4. 리스트 복사 (주소 참조 vs 복사)

* **단순 할당 (`new = original`)**: 메모리 주소만 공유하므로, 복사본을 수정하면 **원본도 함께 수정**됩니다.
* **`.copy()` 메서드**: 독립된 새로운 메모리에 리스트를 생성하므로, 원본에 영향을 주지 않습니다.

```python
nums = [1, 2, 3]

# ❌ 단순 할당 (위험)
bad_copy = nums
bad_copy.append(999) # nums도 [1, 2, 3, 999]로 변경됨!

# ⭕ .copy() 사용 (권장)
good_copy = nums.copy()
good_copy.append(111) # nums에는 영향 없음

```

## 5. 리스트 요소 추가 메서드

> ⚠️ **핵심**: 아래 3가지 추가 메서드는 **원본 리스트를 직접 수정**하므로 **반환값(Return value)이 `None`**입니다.
> (변수에 담거나 `print()`에 직접 넣으면 `None`이 출력됨)

* **`.append(값)`**: 리스트의 **맨 뒤**에 값을 1개 추가합니다.
* **`.insert(인덱스, 값)`**: 지정한 **인덱스 위치**에 값을 삽입합니다. (기존 요소들은 뒤로 밀림)
* **`.extend(리스트)`**: 다른 리스트의 요소들을 **풀어서 기존 리스트 뒤에 이어 붙입니다**.

```python
data = [1, 2, 3]

data.append(4)         # [1, 2, 3, 4]
data.insert(0, 99)     # [99, 1, 2, 3, 4]
data.extend([10, 20])  # [99, 1, 2, 3, 4, 10, 20]

# 반환값 확인 시주의
print(data.append(100)) # None 출력 (리스트 자체는 수정됨)

```

## 6. 리스트 요소 삭제 메서드

1. **`.remove(값)`**
* 인덱스를 모르고 **삭제할 "값"만 알고 있을 때** 사용합니다.
* 리스트에 없는 값을 지우려 하면 `ValueError`가 발생합니다.


2. **`.pop(인덱스)`**
* **인덱스를 기준**으로 요소를 삭제합니다.
* ⭐ **특징**: 삭제한 요소의 값을 반환(Return)해 줍니다.


3. **`del 리스트[인덱스]`**
* 파이썬 키워드로 인덱스를 지정해 삭제합니다.
* **슬라이싱(`del list[::2]`)을 활용해 특정 패턴으로 여러 값을 한 번에 삭제**할 수 있습니다.



```python
list1 = ["딸기", "사과", "포도", "수박"]

list1.remove("딸기")     # ['사과', '포도', '수박']
popped = list1.pop(1)   # 1번 인덱스 '포도' 삭제 및 popped 변수에 저장
print(popped)           # 포도

del list1[0]            # '사과' 삭제
print(list1)            # ['수박']

```

## 7. ⚠️ 핵심 주의사항 요약

| 구분 | 발생 상황 | 에러 종류 / 동작 |
| --- | --- | --- |
| **없는 인덱스 조회** | `list[100]` | ❌ **`IndexError`** |
| **없는 인덱스 슬라이싱** | `list[100:200]` | ⭕ **에러 없음** (`[]` 반환) |
| **없는 값 삭제 시도** | `list.remove("없는값")` | ❌ **`ValueError`** |
| **수정 메서드 출력** | `print(list.append(1))` | ⚠️ **`None` 출력** (원본만 수정됨) |
| **리스트 단순 복사** | `b = a` 후 `b.append()` | ⚠️ **원본 `a`도 함께 변경됨** (`.copy()` 사용 필요) |
