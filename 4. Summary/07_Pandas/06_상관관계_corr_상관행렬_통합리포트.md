```python
# 두 열 상관계수
print(round(df['온도'].corr(df['진동']), 3))
print(round(df['온도'].corr(df['압력']), 3))

num = df[['온도', '진동', '압력']]
print(num.corr().round(3))
```

# ==================== 개념 1. 상관관계 ====================

상관관계는 **한 측정값이 변할 때 다른 측정값이 같이 움직이는지**를 보는 지표입니다.

### 세 방향

```text
양의 방향: A ↑ → B도 ↑
음의 방향: A ↑ → B는 ↓
0 근처   : 뚜렷한 직선 관계가 약함
```

---

# ==================== 개념 2. 상관계수 읽기 ====================

상관계수 범위는 `-1 ~ 1`입니다.

### 부호

- `+` : 같은 방향
- `-` : 반대 방향

### 절댓값

- `1`에 가까울수록 연결이 강함
- `0`에 가까울수록 직선 관계가 약함

교재에서는 절댓값 강도를 우선순위 판단용으로 나누어 보는 표를 제시합니다.

```text
0.9 이상      매우 강한 상관
0.7 ~ 0.9     강한 상관
0.4 ~ 0.7     중간 상관
0.2 ~ 0.4     약한 상관
0.2 미만      거의 무상관
```

> 이 구간은 절대 법칙이라기보다 **어떤 쌍을 먼저 볼지 정하는 우선순위 도구**입니다.

---

# ==================== 개념 3. corr() ====================

```python
print(round(df['온도'].corr(df['진동']), 3))
```

두 Series 사이의 상관계수를 숫자 하나로 구합니다.

```python
print(round(df['온도'].corr(df['압력']), 3))
print(round(df['진동'].corr(df['압력']), 3))
```

---

# ==================== 개념 4. 상관행렬 ====================

여러 열 조합을 한 번에 봅니다.

```python
num = df[['온도', '진동', '압력']]
print(num.corr().round(3))
```

### 읽는 규칙

1. **대각선은 항상 1** → 자기 자신과의 상관
2. 위·아래 대칭 칸은 같은 값
3. 대각선을 제외하고 절댓값이 큰 칸부터 확인
4. 0 근처는 우선순위에서 낮출 수 있음

---

# ==================== 개념 5. 상관관계 ≠ 인과관계 ====================

강한 상관이 있어도:

```text
A가 B의 원인이다
```

라고 바로 결론 내리면 안 됩니다.

상관이 말하는 것:

> 두 값이 함께 움직였다는 **관찰 결과**

상관이 말하지 않는 것:

> 무엇이 원인인지에 대한 직접 결론

원인은 공학적 작동 원리, 현장 지식, 추가 실험으로 따로 검증해야 합니다.

---

# ==================== 개념 6. corr 해석 시 안전장치 ====================

교재에서 강조하는 점:

- 결측이 있는 행은 계산에서 자동 제외될 수 있으므로 실제 표본 수 확인
- 표본 수가 충분한지 확인
- 상관이 0 근처라고 끝내지 말고 산점도 등으로 패턴 검토
- 전체와 그룹별 상관이 다를 수 있으므로 그룹 비교도 고려

---

# ==================== 개념 7. 통합 리포트 ====================

숫자를 계산하는 데서 끝나지 않고 **판단과 행동**으로 연결합니다.

```text
STEP 1. 발견
→ 집계로 확인한 객관적 사실과 구체적 수치

STEP 2. 해석
→ 평균·표준편차·상관 등의 의미 설명

STEP 3. 행동
→ 우선 점검 대상과 모니터링 항목 제안
```

### 리포트 체크

- 구체적 수치가 있는가?
- 왜 그런지 해석했는가?
- 상관을 원인으로 단정하지 않았는가?
- 어떤 설비/센서를 먼저 볼지 행동으로 연결했는가?
