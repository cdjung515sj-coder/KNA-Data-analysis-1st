## 👀 한눈에 배운 코드 정리

```python
# 열 1개 → Series
s = df['형체력']

# 열 여러 개 → DataFrame
sub = df[['형체력', '실린더압력']]

# 열 이름 확인
print(df.columns)

# loc: 이름표 기준
print(df.loc[0])
print(df.loc[0:4])

# iloc: 위치 기준
print(df.iloc[0])
print(df.iloc[0:5])
print(df.iloc[0:2, 1:3])
```

# ==================== 개념 1. 단일 열 선택 ====================

```python
df = pd.read_csv('data/13_diecasting_small.csv')

형체력값 = df['형체력']
print(형체력값)
```

`df['형체력']`처럼 **대괄호 한 겹**으로 열 하나를 선택하면 결과는 `Series`입니다.

### ⚠ Pitfall

```python
df[형체력]      # X: 형체력을 변수로 해석할 수 있음
df['형체력']    # O
```

열 이름은 문자열이므로 따옴표를 씁니다.

---

# ==================== 개념 2. Series vs DataFrame ====================

```python
type(df['형체력'])      # Series
type(df[['형체력']])    # DataFrame
```

### 대괄호 개수로 기억

| 코드 | 결과 |
|---|---|
| `df['형체력']` | Series |
| `df[['형체력']]` | DataFrame |
| `df[['형체력','실린더압력']]` | DataFrame |

> **두 겹은 바구니**라고 생각하면 쉽습니다. 열 하나가 들어 있어도 바구니 형태라 DataFrame입니다.

### 복수 열

```python
두열 = df[['형체력', '실린더압력']]
print(두열.head())

순서변경 = df[['실린더압력', '형체력']]
```

리스트에 적은 순서가 출력 열 순서가 됩니다.

# ==================== 개념 4. loc - 라벨 기준 ====================

`loc`는 **행의 이름표(label)** 를 기준으로 선택합니다.

```python
df.loc[0]
```

여기서 `0`은 첫 번째라는 뜻보다 **인덱스 라벨이 0인 행**이라는 뜻입니다.

### 범위 선택

```python
df.loc[0:4]
```

`loc`는 **끝 라벨을 포함**합니다.

```text
0, 1, 2, 3, 4 → 5줄
```

### 행 + 열 동시 선택

```python
부분 = df.loc[0:2, ['품질등급', '형체력']]
print(부분)

전체행 = df.loc[:, ['형체력', '실린더압력']]
```

형식:

```python
df.loc[행, 열]
```

쉼표 앞 = 행, 뒤 = 열입니다.

### ⚠ Pitfall

```python
df.loc[0]   # O
df.loc(0)   # X
```

`loc` 뒤에는 소괄호가 아니라 **대괄호**를 씁니다.

---

# ==================== 개념 5. iloc - 순서 기준 ====================

`iloc`는 위에서부터 몇 번째인지 **정수 위치**로 선택합니다.

```python
df.iloc[0]      # 첫 번째 행
df.iloc[-1]     # 마지막 행
df.iloc[-3:]    # 마지막 3행
```

### 행 + 열 위치 동시 선택

```python
print(df.iloc[0:2, 1:3])
```

형식:

```python
df.iloc[행번호, 열번호]
```

`i` = integer라고 기억하면 쉽습니다.

---

# ==================== 개념 6. loc vs iloc 핵심 차이 ====================

| 구분 | `loc` | `iloc` |
|---|---|---|
| 기준 | 라벨/이름표 | 정수 위치 |
| 문자 인덱스 | 가능 | 불가 |
| 슬라이싱 끝 | **포함** | **미포함** |
| 예 | `df.loc[0:2]` → 0,1,2 | `df.iloc[0:2]` → 0,1 |

### 가장 자주 틀리는 부분

```python
df.loc[0:2]    # 3줄
df.iloc[0:2]   # 2줄
```

> 외우는 문장: **loc은 부른 이름까지 다 옴 / iloc은 끝 직전까지만 옴.**

---

# ==================== 개념 7. 언제 무엇을 쓰나? ====================

- 열 이름을 안다 → `df['열']`, `df[['열1','열2']]`
- 인덱스 이름표를 안다 → `loc`
- 위에서 몇 번째인지 안다 → `iloc`
- 정확히 N개를 위치 기준으로 자르고 싶다 → `iloc`
- 라벨 범위를 그대로 가져오고 싶다 → `loc`
