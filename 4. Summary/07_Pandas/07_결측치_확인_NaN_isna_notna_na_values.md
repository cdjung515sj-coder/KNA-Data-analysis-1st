## 👀 한눈에 배운 코드 정리

```python
import pandas as pd

df = pd.read_csv('secom_교육샘플.csv')

# -999, 999를 결측으로 인식하면서 읽기
df = pd.read_csv(
    'data.csv',
    na_values=[-999, 999]
)

# 결측 True/False 지도
print(df.isna())

# 열별 결측 개수
print(df.isna().sum())

# 전체 결측 개수
print(df.isna().sum().sum())

# 행별 결측 개수
print(df.isna().sum(axis=1))
```

# ==================== 개념 1. 결측치란? ====================

결측치(Missing Value)는 데이터 표에서 값이 비어 있는 칸입니다.

Pandas에서는 숫자 칸의 빈 값을 주로 `NaN`으로 표시합니다.

```text
0   ≠   NaN
실제 숫자 0   기록 없음
```

---

# ==================== 개념 2. NaN vs None ====================

- `None` : 파이썬의 "아무것도 없음"
- `NaN` : 데이터 도구에서 숫자 쪽 결측을 표시할 때 자주 보는 값

Pandas에서는 둘 다 결측으로 잡히므로 `isna()`로 확인할 수 있습니다.

---

# ==================== 개념 3. 위장된 결측치 ====================

결측이 항상 `NaN` 모습으로만 오지는 않습니다.

### 숫자 0

```text
가동 중 압력 0 → 결측일 가능성
멈춘 설비 속도 0 → 진짜 정상값일 수 있음
```

즉, **0은 맥락을 보고 판단**해야 합니다.

### Sentinel 값

```text
-999, 999, 9999
```

현실에 나오기 어려운 숫자를 "값 없음" 표시로 약속해 둔 경우가 있습니다.

이 값들을 그대로 평균에 넣으면 통계가 크게 왜곡됩니다.

### 빈 문자열 / 공백

글자 열에서는 `""` 또는 공백만 들어 있는 값도 결측처럼 취급해야 할 수 있습니다.

---

# ==================== 개념 4. na_values ====================

위장 결측을 파일을 읽는 순간 NaN으로 바꿀 수 있습니다.

```python
df = pd.read_csv(
    'data.csv',
    na_values=[-999, 999]
)
```

### ⚠ Pitfall

`0`처럼 정상값일 수도 있는 값을 무조건 `na_values`에 넣으면 정상 데이터까지 사라질 수 있습니다.

---

# ==================== 개념 5. info / describe로 결측 단서 보기 ====================

```python
df.info()
```

전체 행 수보다 `Non-Null Count`가 작으면 결측이 있습니다.

```python
df.describe()
```

수치형 열의 `count`가 전체 행 수보다 작으면 결측이 있습니다.

또한 `min=-999`, `max=999` 같은 값은 위장 결측을 의심하는 단서가 됩니다.

---

# ==================== 개념 6. isna / notna ====================

```python
df.isna()
```

- 결측 → `True`
- 값 있음 → `False`

### 같은 기능 이름

```text
isna()   == isnull()
notna()  == notnull()
```

초보 단계에서는 **결측 찾기 = isna()** 하나를 중심으로 기억하면 됩니다.

---

# ==================== 개념 7. 결측 개수 세기 ====================

### 열별

```python
df.isna().sum()
```

Pandas에서 `True=1`, `False=0`처럼 계산되므로 `sum()`하면 True 개수가 됩니다.

### 전체

```python
df.isna().sum().sum()
```

### 행별

```python
df.isna().sum(axis=1)
```

`axis=1`은 가로 방향으로 더해서 **각 행의 빈 칸 수**를 구합니다.

### 결측 비율

예를 들어 250행 중 109개가 결측이면:

```text
109 / 250 × 100 = 43.6%
```

개수와 비율을 같이 봐야 "조금 채울지 / 열을 버릴지" 판단하기 쉽습니다.

### 심한 열부터 정렬

```python
missing = df.isna().sum()
print(missing.sort_values(ascending=False))
```

→ 결측 처리 우선순위를 빠르게 볼 수 있습니다.
