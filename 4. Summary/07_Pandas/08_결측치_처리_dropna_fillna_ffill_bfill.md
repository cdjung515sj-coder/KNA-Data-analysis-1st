## 👀 한눈에 배운 코드 정리

```python
# 결측 행 삭제
clean = df.dropna()

# 결측 열 삭제
clean = df.dropna(axis=1)

# 완전히 빈 행만 삭제
clean = df.dropna(how='all')

# 값이 최소 20개 이상 있는 행만 유지
clean = df.dropna(thresh=20)

# 특정 열을 기준으로 결측 행 삭제
clean = df.dropna(subset=['불량여부'])

# 상수 채우기
df['설비명'] = df['설비명'].fillna('미상')

# 평균 / 중앙값
df['센서09'] = df['센서09'].fillna(df['센서09'].mean())
df['센서09'] = df['센서09'].fillna(df['센서09'].median())

# 최빈값
top = df['제품유형'].mode()[0]
df['제품유형'] = df['제품유형'].fillna(top)

# 시계열 앞/뒤 값
df = df.sort_values('측정시각')
df['온도'] = df['온도'].ffill().bfill()
```

# ==================== 개념 1. 제거 vs 대체 ====================

### 제거

결측이 있는 행/열을 없앱니다.

장점:
- 추측해서 값을 만들지 않음
- 코드가 단순함

단점:
- 결측 한 칸 때문에 같은 행의 멀쩡한 값까지 같이 잃을 수 있음

### 대체

빈 칸만 그럴듯한 값으로 채웁니다.

장점:
- 행 수를 유지할 수 있음

단점:
- 채운 값은 실제 측정값이 아니라 **추정값**
- 너무 많이 채우면 데이터 분포가 인위적으로 변함

---

# ==================== 개념 2. dropna() ====================

### 결측이 하나라도 있는 행 삭제

```python
clean = df.dropna()
```

기본값은 행 방향이고, 결측이 하나라도 있으면 해당 행을 삭제합니다.

### 결측이 있는 열 삭제

```python
clean = df.dropna(axis=1)
```

### 특정 열 직접 삭제

```python
df.drop(columns=['센서19', '센서20'])
```

교재에서는 결측이 특정 센서 열에 심하게 몰려 있으면 **부실 열을 먼저 정리한 뒤 행을 정리**하는 흐름을 권장합니다.

---

# ==================== 개념 3. how / thresh / subset ====================

## `how='all'`

```python
clean = df.dropna(how='all')
```

모든 값이 비어 있는 행만 삭제합니다.

## `thresh`

```python
clean = df.dropna(thresh=20)
```

### 매우 중요

`thresh=20`은

```text
결측 20개면 삭제 X
값이 20개 이상 있으면 유지 O
```

즉 **살아 있는 값의 최소 개수**입니다.

## `subset`

```python
clean = df.dropna(subset=['불량여부'])
```

전체 열이 아니라 지정한 중요 열만 보고 삭제 여부를 판단합니다.

---

# ==================== 개념 4. fillna() ====================

## 상수

```python
df['행사참여'] = df['행사참여'].fillna(0)
df['설비명'] = df['설비명'].fillna('미상')
```

센서 측정값에 무조건 0을 넣으면 평균이 왜곡될 수 있으므로 주의합니다.

## 평균

```python
m = df['센서09'].mean()
df['센서09'] = df['센서09'].fillna(m)
```

고르게 퍼진 수치 데이터에서 자연스럽지만 이상치에 영향을 받습니다.

## 중앙값

```python
m = df['센서09'].median()
df['센서09'] = df['센서09'].fillna(m)
```

이상치나 치우친 분포가 있을 때 평균보다 안전합니다.

### 평균 vs 중앙값

```text
평균과 중앙값이 비슷 → 평균 고려
두 값이 많이 다름     → 중앙값 고려
헷갈리면 중앙값이 더 안전한 경우가 많음
```

## 최빈값 - 범주형

```python
top = df['제품유형'].mode()[0]
df['제품유형'] = df['제품유형'].fillna(top)
```

글자/등급 같은 범주형은 평균이 없으므로 가장 자주 나온 값으로 채울 수 있습니다.

---

# ==================== 개념 5. ffill() ====================

바로 앞의 정상값을 가져옵니다.

```python
df = df.sort_values('측정시각')
df['온도'] = df['온도'].ffill()
```

```text
73, NaN, NaN, 75
↓
73, 73, 73, 75
```

설비 상태가 짧은 시간에 급변하지 않는다는 가정 아래 **짧은 결측 구간**에 자연스럽습니다.

### ⚠ 필수 체크

- 시간 순서 정렬
- 결측이 너무 길지 않은지
- 서로 다른 설비 값이 섞이지 않는지

---

# ==================== 개념 6. bfill() ====================

뒤의 값을 앞으로 당겨 채웁니다.

```python
df['온도'] = df['온도'].bfill()
```

특히 맨 앞이 NaN이면 `ffill()`로 못 채우므로 보완할 수 있습니다.

```python
df['온도'] = (
    df['온도']
    .ffill()
    .bfill()
)
```

교재의 기본 생각:

> **ffill로 대부분 채우고, 맨 앞에 남은 결측을 bfill로 보완.**

---

# ==================== 개념 7. 그룹별 평균으로 채우기 ====================

같은 종류끼리 값 특성이 다르면 전체 평균보다 그룹 평균이 더 자연스럽습니다.

```python
df['토크'] = (
    df.groupby('제품유형')['토크']
      .transform(lambda x: x.fillna(x.mean()))
)
```

→ L 그룹의 빈 토크는 L 평균, M 그룹은 M 평균.

### ⚠ Pitfall

그룹이 너무 작으면 그 그룹 평균 자체가 불안정할 수 있습니다.

# ==================== 개념 8. inplace 주의 + 검증 ====================

교재에서는 처리 결과를 변수에 다시 담는 방식을 권장합니다.

```python
df = df.fillna(0)

clean = df.fillna(0)
```

처리 후에는 반드시 검증합니다.

```python
print(df.isna().sum().sum())
```

`0`이면 결측이 모두 사라졌다는 뜻입니다.
