2. 평균만 보면 놓치는 흩어짐
3. 분산 `var()`
4. 표준편차 `std()`
5. 평균과 중앙값 비교
6. `agg()`로 여러 통계 한 번에

---

## 👀 한눈에 배운 코드 정리

```python
# 그룹별 분산
df.groupby('냉각기상태')['온도'].var().round(2)

# 그룹별 표준편차
df.groupby('냉각기상태')['온도'].std().round(2)

# 그룹별 중앙값
df.groupby('냉각기상태')['온도'].median().round(2)

# 여러 통계 한 번에
df.groupby('냉각기상태')['온도'] \
  .agg(['mean', 'std', 'max']) \
  .round(2)

# 이름 붙여서 집계
df.groupby('냉각기상태').agg(
    평균온도=('온도', 'mean'),
    온도편차=('온도', 'std'),
    측정수=('온도', 'count'),
).round(2)
```

---

# ==================== 개념 1. 평균은 가운데 수준만 알려준다 ====================

평균은 많은 값을 하나의 숫자로 압축한 대푯값입니다.

```python
df.groupby('냉각기상태')['온도'].mean()
```

하지만 평균이 같다고 두 설비가 같은 상태인 것은 아닙니다.

```text
설비 A: 76 ~ 80도
설비 B: 50 ~ 105도
평균은 둘 다 78도일 수 있음
```

따라서 평균 옆에는 **흩어짐**을 같이 봐야 합니다.

---

# ==================== 개념 2. 분산 var() ====================

분산은 값들이 평균에서 얼마나 흩어져 있는지 나타냅니다.

```python
df.groupby('냉각기상태')['온도'].var().round(2)
```

### 특징

- 크면 값이 들쭉날쭉
- 작으면 평균 근처에 모임
- 거리 차이를 제곱해서 계산하므로 단위도 제곱됨

### ⚠ 주의

분산은 단위가 `℃²`처럼 제곱이 되어 직관적인 해석은 어렵습니다.

---

# ==================== 개념 3. 표준편차 std() ====================

표준편차는 분산에 제곱근을 씌운 값입니다.

```python
df.groupby('냉각기상태')['온도'].std().round(2)
```

원래 데이터와 같은 단위를 사용하므로 실무에서 해석하기 쉽습니다.

| 구분 | 분산 `var` | 표준편차 `std` |
|---|---|---|
| 의미 | 흩어짐 | 흩어짐 |
| 단위 | 원래 단위의 제곱 | 원래 단위 |
| 관계 | `std²` | `sqrt(var)` |

> 하나만 기억한다면 교재에서는 **표준편차**를 더 실용적인 지표로 강조합니다.

---

# ==================== 개념 4. 평균 + 표준편차를 한 쌍으로 ====================

설비 상태를 볼 때:

```text
평균 정상 + 편차 작음 → 안정
평균 정상 + 편차 큼   → 평균은 괜찮아도 불안정
평균 높음 + 편차 작음 → 일관되게 높은 상태
평균 높음 + 편차 큼   → 높고 불안정한 고위험 상태
```

즉, **수준(mean)** 과 **안정성(std)** 을 같이 봅니다.

---

# ==================== 개념 5. mean vs median ====================

```python
mean_v = df.groupby('냉각기상태')['온도'].mean()
median_v = df.groupby('냉각기상태')['온도'].median()
```

평균과 중앙값 차이가 크면 한쪽에 극단값이나 치우친 값이 있을 가능성을 의심할 수 있습니다.

- 평균: 모든 값의 영향을 받음
- 중앙값: 순서상 가운데라 극단값 영향이 상대적으로 작음

---

# ==================== 개념 6. agg() ====================

통계를 하나씩 따로 계산하지 않고 한 번에 묶습니다.

```python
df.groupby('냉각기상태')['온도'] \
  .agg(['mean', 'std', 'max']) \
  .round(2)
```

결과는 그룹이 행, 통계가 열인 표가 됩니다.

---

# ==================== 개념 7. named aggregation ====================

보고서처럼 보기 좋은 열 이름을 만들 때 사용합니다.

```python
df.groupby('냉각기상태').agg(
    평균온도=('온도', 'mean'),
    온도편차=('온도', 'std'),
    측정수=('온도', 'count'),
).round(2)
```

형식:

```python
결과열이름 = ('원본열', '통계함수')
```

여러 열과 여러 통계를 한 표에 정리할 때 가장 깔끔합니다.
