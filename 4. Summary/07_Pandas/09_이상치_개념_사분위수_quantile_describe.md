# ==================== 개념 1. 이상치란? ====================

이상치는 다른 값들과 크게 동떨어진 값입니다.

예:

```text
72, 75, 78, 250
```

`250`은 평소 값과 크게 떨어져 있습니다.

하지만 **발견 즉시 삭제하면 안 됩니다.** 제조 데이터에서는 이상치가 실제 고장 신호일 수도 있기 때문입니다.

---

# ==================== 개념 2. 노이즈 vs 신호 ====================

### 노이즈 이상치

센서 오류, 입력 오류 등으로 잘못 들어온 값.

```text
물리적으로 불가능한 온도
자리수 입력 실수
```

→ 정리 후보

### 신호 이상치

설비가 실제로 평소와 다르게 움직여 생긴 값.

```text
베어링 마모로 진동 급증
냉각 불량으로 온도 상승
```

→ 고장 단서이므로 **보존해야 할 수 있음**

### 핵심 질문

> "이 값을 지울까?"보다 먼저 **"노이즈인가, 신호인가?"**

# ==================== 개념 3. 결측치 vs 이상치 ====================

| 구분 | 결측치 | 이상치 |
|---|---|---|
| 상태 | 값이 비어 있음 | 값은 있으나 동떨어짐 |
| 예 | `NaN` | `250` |
| 찾는 방법 | `isna()` | 분포·IQR 등 |

이상치는 값이 채워져 있으므로 `isna()`로 잡히지 않습니다.

# ==================== 개념 4. 사분위수 ====================

데이터를 크기순으로 놓고 4등분했을 때의 기준점입니다.

```text
Q1 = 25% 지점
Q2 = 50% 지점 = 중앙값
Q3 = 75% 지점
```

Q1~Q3 사이에는 가운데 50% 데이터가 들어 있습니다.

극단값이 있어도 가운데 구간을 중심으로 보기 때문에 평균보다 덜 흔들릴 수 있습니다.

---

# ==================== 개념 5. 백분위수와 quantile ====================

`quantile()` 괄호 안에는 **0~1 사이 비율**을 넣습니다.

```python
Q1 = df['temperature'].quantile(0.25)
Q2 = df['temperature'].quantile(0.5)
Q3 = df['temperature'].quantile(0.75)
```

### 한 번에

```python
print(df['temperature'].quantile([0.25, 0.5, 0.75]))
```

### ⚠ Pitfall

```python
.quantile(25)     # X
.quantile(0.25)   # O
```

25%는 `25`가 아니라 `0.25`입니다.

# ==================== 개념 6. describe()로 분포 읽기 ====================

```python
print(df['temperature'].describe())
```

예시 항목:

```text
count
mean
std
min
25%
50%
75%
max
```

### 이상치 단서

- 평균과 중앙값(50%) 차이가 매우 큼
- `min`/`max`가 사분위수와 너무 멀리 떨어짐

→ 이상치 후보가 있는지 추가로 살펴볼 단서입니다.

---

# ==================== 개념 7. 박스플롯 읽기 ====================

교재에서는 박스플롯을 그리는 법보다 **읽는 법**에 집중합니다.

```text
상자        = Q1 ~ Q3, 가운데 50%
상자 안 선 = 중앙값 Q2
수염 밖 점 = 이상치 후보
```

이 구조가 다음 파일의 **IQR 이상치 공식**으로 바로 이어집니다.
