# ==================== 개념 1. EDA는 왜 먼저 하나? ====================

데이터를 받자마자 분석이나 모델링부터 하지 않습니다. 먼저 **크기, 내용, 결측치, 자료형, 이상한 수치**가 있는지 확인해야 뒤의 계산이 왜곡되지 않습니다.

### 먼저 볼 3가지

- **크기**: 몇 행 × 몇 열인가?
- **내용**: 어떤 열이 있고 값이 어떤 모양인가?
- **이상 신호**: NaN이나 비정상적으로 튄 값이 있는가?

---

# ==================== 개념 2. head() / tail() ====================

```python
df.head()      # 위에서 5줄
df.head(10)    # 위에서 10줄

df.tail()      # 아래에서 5줄
df.tail(3)     # 아래에서 3줄
```

- `head()` : 열 이름, 초반 데이터 패턴, NaN을 빠르게 확인
- `tail()` : 파일 마지막 부분, 최신 시점 데이터, 끝부분 이상 여부 확인

### ⚠ Pitfall

`head()`에서 NaN이 안 보인다고 **결측치가 없다고 단정하면 안 됩니다.** 전체 결측은 `info()`나 `isna().sum()`으로 따로 확인해야 합니다.

# ==================== 개념 3. DataFrame의 뼈대 속성 ====================

```python
print(df.shape)
print(df.columns)
print(df.index)
print(df.dtypes)
```

### `df.shape`

```text
(200, 7)
```

→ 200행 7열

### `df.columns`

→ 모든 열 이름을 확인합니다. 이후 열 선택할 때 정확한 이름을 알아야 합니다.

### `df.index`

→ 행의 이름표입니다. 기본 인덱스라면 보통 `0`부터 시작합니다.

### `df.dtypes`

→ 각 열의 자료형을 확인합니다.

- `int64` : 정수
- `float64` : 실수
- `object` : 글자 데이터로 읽힌 경우가 많음

### ⚠ 가장 중요한 주의

```python
df.shape      # O
df.shape()    # X
```

`shape`, `columns`, `index`, `dtypes`는 **속성**이므로 `()`를 붙이지 않습니다.

---

# ==================== 개념 4. dtypes를 꼭 확인하는 이유 ====================

### 숫자 센서가 `object`로 들어오면

특수문자·공백·문자 오류가 섞인 경우 `mean()` 같은 숫자 계산이 안 될 수 있습니다.

### ID가 숫자로 들어오면

`00123` 같은 코드가 `123`으로 바뀌어 앞의 0이 사라질 수 있습니다.

> 분석 시작 전 `df.dtypes`를 한 번 확인하면 뒤에서 생길 오류를 많이 줄일 수 있습니다.

# ==================== 개념 5. info() ====================

```python
df.info()
```

`info()`가 보여주는 것:

- 전체 행 수
- 전체 열 수와 열 이름
- 각 열의 **Non-Null Count**
- 각 열의 자료형(Dtype)
- 메모리 사용량

### Non-Null로 결측 찾기

전체 200행인데:

```text
오일온도 196 non-null
```

이라면

```text
200 - 196 = 결측 4개
```

입니다.

# ==================== 개념 6. describe() ====================

```python
print(df.describe())
```

수치형 열의 대표 통계를 한 번에 보여줍니다.

| 항목 | 의미 |
|---|---|
| `count` | 결측이 아닌 데이터 수 |
| `mean` | 평균 |
| `std` | 표준편차 |
| `min` | 최솟값 |
| `25%` | 1사분위수 Q1 |
| `50%` | 중앙값 Q2 |
| `75%` | 3사분위수 Q3 |
| `max` | 최댓값 |

### 이상 신호를 보는 간단한 방법

`75%`와 `max`가 매우 멀리 떨어져 있으면 상단에 극단값이 있을 가능성을 의심합니다.

> `describe()`는 이상치를 **확정**하는 함수가 아니라 **추가 조사할 열을 찾는 출발점**입니다.

# ==================== 개념 7. 데이터 첫 탐색 4종 세트 ====================

```python
import pandas as pd

df = pd.read_csv("data/12_metro_compressor.csv")

print("데이터 크기:", df.shape)
print(df.head(3))
df.info()
print(df.describe())
```

## ✅ 외우는 순서

```text
HEAD     → 실제 값이 어떻게 생겼나?
SHAPE    → 데이터가 얼마나 큰가?
INFO     → 자료형·결측에 문제 있나?
DESCRIBE → 숫자 분포가 이상하지 않나?
```
