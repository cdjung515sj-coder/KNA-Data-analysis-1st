# 🧰 프로그래밍 기초: 사용된 함수(Function) 총정리
---
## 📥 1. 입출력 및 기본 내장함수

프로그램의 가장 기본이 되는 화면 출력, 사용자 입력, 데이터 상태 확인을 위한 함수입니다.

| 함수 형태 | 역할 | 예시 코드 | 출력/기능 결과 |
| --- | --- | --- | --- |
| **`print()`** | 괄호 안의 데이터를 화면에 출력합니다. | `print("안녕")` | 화면에 `안녕` 표시 |
| **`input()`** | 사용자에게 키보드로 값을 입력받습니다. *(무조건 문자열로 저장)* | `name = input("이름: ")` | 사용자가 입력한 값을 변수에 저장 |
| **`len()`** | 문자열의 글자 수나 리스트의 요소 개수를 반환합니다. | `len("Python")` | `6` (글자 수) |

---

## 🔄 2. 형변환 함수 (Type Casting Functions)

데이터의 자료형(성격)을 강제로 바꾸어 계산이나 조작이 가능하게 만드는 함수들입니다.

| 함수 형태 | 목적 자료형 | 예시 코드 | 변환 결과 |
| --- | --- | --- | --- |
| **`int()`** | 정수형 (`int`)으로 변환 | `int("10")` / `int(3.14)` | 정수 `10` / 정수 `3` |
| **`float()`** | 실수형 (`float`)으로 변환 | `float("3.14")` / `float(10)` | 실수 `3.14` / 실수 `10.0` |
| **`str()`** | 문자열 (`str`)로 변환 | `str(100)` | 문자열 `"100"` (텍스트 화) |
| **`bool()`** | 불리언 (`bool`)으로 변환 | `bool(1)` / `bool(0)` | `True` / `False` |

---

## 🔤 3. 문자열 전용 내장 기능 (String Methods)

문자열(String) 데이터 뒤에 점(`.`)을 붙여서 글자를 요리 조리 가공하는 함수들입니다.

### `.strip()` : 앞뒤 공백 제거

* **설명:** 문자열 앞뒤에 들어간 불필요한 띄어쓰기나 줄바꿈을 깔끔하게 지워줍니다.
* **예시:** `"  Hello  ".strip()` ➔ 결과: `"Hello"`

### `.replace(기존글자, 바꿀글자)` : 글자 치환

* **설명:** 문자열 내에서 특정 단어나 글자를 찾아 다른 글자로 싹 바꿔줍니다.
* **예시:** `"I love Python".replace("Python", "Coding")` ➔ 결과: `"I love Coding"`

### `.split(기준글자)` : 문자열 쪼개기

* **설명:** 기준이 되는 글자(쉼표, 공백 등)를 기준으로 텍스트를 쪼개어 묶음(리스트)으로 만들어줍니다.
* **예시:** `"사과,바나나".split(",")` ➔ 결과: `["사과", "바나나"]` (리스트 자료형이 됨)

---

## 💡 한눈에 보는 실전 조립 예시

실제 코딩을 할 때는 아래처럼 **여러 개의 함수를 한 줄로 조립**해서 쓰는 경우가 많습니다.

```python
# [조립 패턴 1] 사용자의 입력을 받자마자 정수로 바꾸기
age = int(input("나이를 입력하세요: "))
# 해석: input()으로 입력받은 문자를 -> int()가 곧바로 숫자로 변경함.

# [조립 패턴 2] 숫자를 문자로 바꿔서 텍스트와 이어붙이기
level = 5
print("현재 레벨은 " + str(level) + "입니다.")
# 해석: 숫자 5를 -> str()로 문자 "5"로 바꾼 뒤 -> 더하기(+) 연산자로 문장 조립.

```


# 📝 프로그래밍 기초: 자료형 (Data Type) 총정리

프로그래밍에서 자료형(Data Type)은 컴퓨터에게 "내가 사용할 데이터가 어떤 종류인지" 알려주는 일종의 분류판입니다. 모든 프로그래밍 언어의 뼈대가 되는 핵심 개념입니다.

---

## 📦 1. 기본 자료형 (Primitive Types)

더 이상 쪼갤 수 없는 가장 단순한 형태의 단일 데이터입니다.

| 자료형 | 표기 명칭 (약어) | 형태 예시 | 한줄 요약 |
| --- | --- | --- | --- |
| **정수형** | Integer (`int`) | `10`, `-5`, `0` | 소수점이 없는 순수 숫자 (연산 가능) |
| **실수형** | Float / Double | `3.14`, `-0.5` | 소수점이 포함된 숫자 (연산 가능) |
| **문자열** | String (`str`) | `"Hello"`, `"123"` | **따옴표**로 감싸진 모든 글자 (연산 불가) |
| **불리언** | Boolean (`bool`) | `True`, `False` | 참과 거짓, 딱 두 가지만 존재하는 논리값 |
| **빈 값** | Null / None / Undefined | `null`, `None` | "아무런 값도 들어있지 않다"를 명시하는 값 |

---

## 🧺 2. 컨테이너 자료형 (Container / Collection Types)

기본 데이터들을 여러 개 묶어서 한 번에 관리하는 바구니 형태의 자료형입니다.

### 1) 리스트 / 배열 (List / Array)

* **모양 (괄호):** 대괄호 `[ ]`
* **구조 예시:** `["사과", "바나나", "포도"]`
* **핵심 특징:** 데이터에 순서(Index)가 있습니다. 컴퓨터는 번호를 0번부터 매기기 때문에, 0번 방은 `"사과"`, 1번 방은 `"바나나"`가 됩니다. 순서대로 정렬해야 할 때 사용합니다.

### 2) 딕셔너리 / 객체 (Dictionary / Object)

* **모양 (괄호):** 중괄호 `{ }`
* **구조 예시:** `{"이름": "홍길동", "나이": 20}`
* **핵심 특징:** 데이터에 **이름표**가 붙어 있습니다. `Key(키): Value(값)`가 항상 한 쌍으로 움직입니다. 순서 대신 이름으로 데이터를 찾고 싶을 때 사용합니다.

### 3) 튜플 (Tuple)

* **모양 (괄호):** 소괄호 `( )`
* **구조 예시:** `(1, 2, 3)`
* **핵심 특징:** 리스트와 똑같이 순서가 있지만, "한 번 만들면 내부의 값을 절대 바꿀 수 없다"는 보안 규칙이 있습니다. 프로그램이 실행되는 동안 값이 변하면 안 되는 중요 데이터(예: GPS 위도/경도)를 관리할 때 씁니다.

### 4) 집합 (Set)

* **모양 (괄호):** 중괄호 `{ }`
* **구조 예시:** `{"A", "B"}`
* **핵심 특징:** **중복을 허용하지 않습니다.** 중괄호 안에 똑같은 값을 아무리 많이 넣어도 컴퓨터는 중복을 지우고 딱 하나만 남깁니다. 순서도 무작위로 저장됩니다.

---

## ⚠️ 주의해야 할 핵심 포인트 (숫자 vs 문자)

컴퓨터는 모양이 숫자여도 **따옴표**가 붙는 순간 숫자가 아닌 **글자**로 인식합니다. 이 차이로 인해 전혀 다른 결과가 나옵니다.

> * `10 + 20` ➔ **`30`** (숫자형끼리의 산술 연산)
> * `"10" + "20"` ➔ **`"1020"`** (문자열끼리 글자를 이어붙임)

# ⚙️ 프로그래밍 기초: 연산자 (Operator) 총정리

프로그래밍에서 연산자(Operator)는 변수나 값을 가지고 **계산, 비교, 조작 등 어떤 작업을 수행할지 결정하는 기호**들입니다. 프로그래밍 언어의 '계산기 버튼'이자 '비교 규칙'이라고 보시면 됩니다.

---

## 🔢 1. 산술 연산자 (Arithmetic Operators)

가장 기본이 되는 수학 계산 연산자입니다. 숫자를 다룰 때 사용합니다.

| 연산자 | 기능 | 예시 (x=10, y=3) | 결과 | 한줄 설명 |
| --- | --- | --- | --- | --- |
| `+` | 더하기 | `x + y` | `13` | 두 값을 더함 |
| `-` | 빼기 | `x - y` | `7` | 앞의 값에서 뒤의 값을 뺀 |
| `*` | 곱하기 | `x * y` | `30` | 두 값을 곱함 (키보드의 별표 기호) |
| `/` | 나누기 | `x / y` | `3.333...` | 앞의 값을 뒤의 값으로 나눈 몫(실수형) |
| `%` | 나머지 | `x % y` | `1` | 나눈 뒤 **남은 나머지** 값 (홀짝 판별에 자주 씀) |
| `//` | 몫 나누기 | `x // y` | `3` | 나눈 결과에서 소수점을 버리고 **정수 몫**만 남김 |
| `**` | 거듭제곱 | `x ** y` | `1000` | x의 y제곱 (10의 3제곱) |

> 💡 `//`와 `**` 연산자는 파이썬(Python) 등 일부 언어에서 기본으로 지원하는 편리한 연산자입니다.

---

## 📥 2. 대입/할당 연산자 (Assignment Operators)

오른쪽에 있는 값을 왼쪽의 변수(상자)에 **집어넣을 때(저장할 때)** 사용합니다.

| 연산자 | 기능 | 예시 | 실제 의미 |
| --- | --- | --- | --- |
| `=` | 대입 | `x = 10` | x라는 상자에 10을 넣는다. (수학의 '같다'가 아님!) |
| `+=` | 더해서 대입 | `x += 5` | `x = x + 5` (현재 x값에 5를 더해서 다시 x에 저장) |
| `-=` | 빼서 대입 | `x -= 3` | `x = x - 3` (현재 x값에서 3을 빼서 다시 x에 저장) |
| `*=` | 곱해서 대입 | `x *= 2` | `x = x * 2` (현재 x값에 2를 곱해서 다시 x에 저장) |
| `/=` | 나눠서 대입 | `x /= 2` | `x = x / 2` (현재 x값을 2로 나눠서 다시 x에 저장) |

---

## ⚖️ 3. 비교 연산자 (Comparison Operators)

두 값을 비교하여 맞으면 `True(참)`, 틀리면 `False(거짓)`라는 **불리언(Boolean) 결과**를 만들어내는 연산자입니다. 조건문(`if`)에서 가장 많이 쓰입니다.

| 연산자 | 기능 | 예시 (x=10, y=3) | 결과 | 주의사항 |
| --- | --- | --- | --- | --- |
| `==` | 같다 | `x == y` | `False` | **등호가 2개**여야 '같다'라는 비교가 됩니다. |
| `!=` | 다르다 | `x != y` | `True` | 두 값이 다르면 참(True)이 됩니다. |
| `>` | 크다 (초과) | `x > y` | `True` | 왼쪽이 오른쪽보다 크면 참 |
| `<` | 작다 (미만) | `x < y` | `False` | 왼쪽이 오른쪽보다 작으면 참 |
| `>=` | 크거나 같다 (이상) | `x >= y` | `True` | 꺾쇠가 항상 등호보다 먼저 옵니다. (`=>` X) |
| `<=` | 작거나 같다 (이하) | `x <= y` | `False` | 꺾쇠가 항상 등호보다 먼저 옵니다. (`<=` O) |

---

## 🧠 4. 논리 연산자 (Logical Operators)

참(`True`)과 거짓(`False`)을 가지고 한 번 더 계산하는 연산자입니다. "A도 맞고 B도 맞을 때" 같은 복잡한 조건을 만들 때 씁니다.

| 연산자 (Python) | 연산자 (JS/C계열) | 기능 (이름) | 설명 | 예시 |
| --- | --- | --- | --- | --- |
| `and` | `&&` | 그리고 (논리곱) | **모든 조건이 참(`True`)**이어야만 최종 `True`가 됨 | `(10 > 5) and (3 > 5)` ➔ `False` |
| `or` | `||` | 또는 (논리합) | 조건 중 **하나라도 참(`True`)**이면 최종 `True`가 됨 | `(10 > 5) or (3 > 5)` ➔ `True` |
| `not` | `!` | ~가 아니다 (논리부정) | 결과를 **반대로 뒤집음** (`True` ➔ `False`, `False` ➔ `True`) | `not (10 > 5)` ➔ `False` |

---

## ⚠️ 초보자가 반드시 헷갈리는 포인트 (`=` vs `==`)

코딩을 처음 할 때 가장 많이 내는 에러 중 하나입니다. 컴퓨터에게 두 기호는 완전히 다른 명령입니다.

* `x = 10` ➔ **명령:** "x라는 변수에 10을 **저장해!**" (대입 연산자)
* `x == 10` ➔ **질문:** "지금 x 안에 들어있는 값이 10이랑 **똑같아?**" (비교 연산자 ➔ 결과는 `True` 또는 `False`)

# 🚀 자료형과 연산자 실전 활용 예시

자료형(식재료)과 연산자(도구)를 결합하면 컴퓨터에게 다양한 논리적 명령을 내릴 수 있습니다.

---

## 🛒 예시 1: 쇼핑몰 장바구니 계산 (산술 + 대입 연산자)

물건 가격과 수량을 계산하고, 할인 쿠폰을 적용한 뒤 최종 결제 금액을 구하는 흐름입니다.

```python
# 1. 변수에 기본 자료형 데이터 저장 (대입 연산자 '=')
apple_price = 1500  # 정수형 (int)
apple_count = 3     # 정수형 (int)
discount_rate = 0.1 # 실수형 (float) - 10% 할인율

# 2. 총 금액 계산 (산술 연산자 '*')
total_price = apple_price * apple_count
print(total_price)  # 출력 결과: 4500

# 3. 할인 적용 및 최종 금액 업데이트 (대입 연산자 '-=')
# 4500원의 10%인 450원을 총 금액에서 뺍니다.
total_price -= total_price * discount_rate
print(total_price)  # 출력 결과: 4050.0 (실수가 곱해져서 실수형으로 변환됨)

```

---

## 🔐 예시 2: 로그인 시스템 검증 (비교 + 논리 연산자)

사용자가 입력한 아이디/비밀번호가 서버에 저장된 정보와 둘 다 일치하는지 확인하는 조건문입니다.

```python
# 1. 서버에 저장된 올바른 회원 정보 (문자열형 str)
db_id = "coding_master"
db_pw = "pass1234"

# 2. 사용자가 로그인 창에 입력한 값
input_id = "coding_master"
input_pw = "wrong_password"

# 3. 아이디와 비밀번호가 모두 맞는지 검증 (비교 연산자 '==' + 논리 연산자 'and')
# 결과적으로 True and False 가 되어 최종 결과는 False(거짓)가 됩니다.
is_login_success = (db_id == input_id) and (db_pw == input_pw)

print(is_login_success)  # 출력 결과: False (불리언형 bool)

```

## 🏷️ 예시 3: 회원 등급별 안내 문구 생성 (문자열 + 리스트 자료형)

문자열을 서로 이어 붙이거나, 리스트 안에 든 데이터를 순서대로 꺼내 쓰는 형태입니다.

```python
# 1. 문자열과 정수형 데이터 선언
user_name = "홍길동"
user_level = 3

# 2. 문자열 더하기 연산 (텍스트 이어붙이기)
# 주의: 숫자인 user_level을 str()을 이용해 문자열 "3"으로 바꾸어 더해야 에러가 안 납니다.
welcome_message = user_name + "님, 환영합니다! 현재 등급은 " + str(user_level) + "입니다."
print(welcome_message)  # 출력 결과: 홍길동님, 환영합니다! 현재 등급은 3입니다.

# 3. 리스트에서 순서(Index)를 이용해 혜택 꺼내기
# 0번: 일반 혜택, 1번: 실버 혜택, 2번: 골드 혜택
rewards = ["무료 배송", "5% 할인 쿠폰", "10% 할인 쿠폰 + 무료 배송"]
print(rewards[2])  # 출력 결과: 10% 할인 쿠폰 + 무료 배송 (2번 방 데이터 꺼내기)

```

## 💡 예시 4: 짝수/홀수 판별기 (나머지 연산자 활용)

웹사이트에서 게시판 글을 한 줄씩 번갈아가며 회색/흰색으로 칠하거나, 짝수 번호 회원에게 이벤트를 할 때 정말 자주 쓰이는 공식입니다.

```python
# 어떤 숫자가 주어졌을 때
target_number = 27

# 2로 나눈 나머지가 0이면 짝수, 1이면 홀수입니다. (나머지 연산자 '%')
is_even = (target_number % 2 == 0)

print(is_even)  # 출력 결과: False (27은 2로 나누면 나머지가 1이므로 False 즉, 홀수입니다.)

```

# 📥 프로그래밍 기초: 입력, 형변환, 문자열 활용 총정리

사용자가 값을 직접 입력하게 만들고, 데이터의 종류를 바꾸며, 문자열(텍스트)을 자유자재로 요리하는 방법입니다. (가장 직관적인 **파이썬** 언어 기준)

---

## 📥 1. 입력 (Input)

프로그램이 일방적으로 실행되는 것이 아니라, **사용자가 키보드로 입력한 값을 프로그램 속으로 받아오는 기능**입니다.

### 💡 핵심 규칙: 입력받은 것은 무조건 "문자열"이다

컴퓨터는 사용자가 숫자를 쳤는지, 글자를 쳤는지 알지 못합니다. 따라서 `input()`으로 받아온 모든 데이터는 일단 문자열(`str`)형태로 저장됩니다.

```python
# 사용자의 이름을 입력받아 변수에 저장
user_name = input("이름을 입력하세요: ") 

# 사용자가 숫자 25를 입력하더라도, 컴퓨터는 문자열 "25"로 받아들임
user_age = input("나이를 입력하세요: ") 

print(user_name + "님의 나이는 " + user_age + "세입니다.")

```

---

## 🔄 2. 형변환 (Type Casting)

자료형을 **상황에 맞게 다른 자료형으로 강제로 바꾸는 것**을 말합니다.
앞서 `input()`으로 받은 숫자 모양의 문자열을 진짜 숫자로 바꿔서 계산해야 할 때 반드시 사용됩니다.

### 대표적인 형변환 함수

| 함수 구조 | 변환 목표 | 예시 | 결과 |
| --- | --- | --- | --- |
| `int(값)` | **정수형**으로 변환 | `int("10")` / `int(3.14)` | 정수 `10` / 정수 `3` (소수점 버림) |
| `float(값)` | **실수형**으로 변환 | `float("3.14")` / `float(10)` | 실수 `3.14` / 실수 `10.0` |
| `str(값)` | **문자열**로 변환 | `str(100)` / `str(True)` | 문자열 `"100"` / 문자열 `"True"` |
| `bool(값)` | **불리언**으로 변환 | `bool(1)` / `bool(0)` | 참 `True` / 거짓 `False` (0이나 빈 값은 False가 됨) |

### 🛠️ 실전 활용 패턴 (입력 + 형변환)

```python
# ❌ 잘못된 예시 (에러 발생)
age = input("나이 입력: ") # 사용자가 20 입력 -> 문자열 "20" 저장
next_year_age = age + 1   # 🚨 에러! 문자열("20")과 숫자(1)는 더할 수 없음

#  올바른 예시
age_str = input("나이 입력: ") # 문자열 "20"을 받아서
age_int = int(age_str)         # 진짜 숫자 20으로 형변환!
next_year_age = age_int + 1    # ➔ 결과: 21 (정상 계산)

# 😎 한 줄로 줄여 쓰는 축약형 (가장 많이 씀)
age = int(input("나이를 입력하세요: ")) # 입력받자마자 바로 숫자로 변환

```

## 🔤 3. 문자열 다루기 (String Manipulation)

문자열은 단순히 글자를 보여주는 것 외에, 글자를 쪼개거나 바꾸는 등 다양한 요리가 가능합니다.

### ① 문자열 인덱싱 (Indexing)과 슬라이싱 (Slicing)

문자열을 **글자 배열**로 보고 특정 위치의 글자만 쏙쏙 골라내는 기법입니다. (숫자는 0번부터 셉니다.)

```python
text = "Python"

# 인덱싱: 번호 지정해서 한 글자만 가져오기
print(text[0])  # 결과: 'P' (첫 번째 글자)
print(text[-1]) # 결과: 'n' (맨 뒤에서 첫 번째 글자)

# 슬라이싱: 범위를 지정해서 덩어리로 잘라오기 [시작번호:끝번호번호직전]
# [0:3]은 0번부터 3번 직전(2번)까지 잘라옵니다.
print(text[0:3]) # 결과: 'Pyt'

```

### ② 자주 쓰는 문자열 내장 기능 (메서드)

문자열 뒤에 점(`.`)을 찍어 사용할 수 있는 편리한 내장 기능들입니다.

```python
sample = "  Hello, Python!  "

# 1. len() : 문자열 전체 길이(글자 수) 구하기
print(len(sample)) # 결과: 18 (공백 포함)

# 2. strip() : 앞뒤에 쓸데없이 들어간 공백(띄어쓰기) 제거하기
print(sample.strip()) # 결과: "Hello, Python!"

# 3. replace(A, B) : A라는 글자를 B로 바꾸기
print(sample.replace("Python", "World")) # 결과: "  Hello, World!  "

# 4. split(기준값) : 특정 글자를 기준으로 문자열을 쪼개서 리스트로 만들기
fruits = "사과,바나나,포도"
print(fruits.split(",")) # 결과: ['사과', '바나나', '포도'] (리스트 자료형으로 변환됨)

```
