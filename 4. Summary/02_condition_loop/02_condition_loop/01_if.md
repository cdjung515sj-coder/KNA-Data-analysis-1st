## 💡 한 줄 요약

조건문은 조건의 결과가 `True`인지 `False`인지에 따라 서로 다른 코드를 실행하는 문법이다.

---

## ✅ 핵심 요약

| 문법      | 의미                | 사용하는 상황         |
| ------- | ----------------- | --------------- |
| `if`    | 조건이 참일 때 실행       | 온도가 기준보다 높은지 검사 |
| `else`  | `if` 조건이 거짓일 때 실행 | 정상·경고 중 하나 출력   |
| `elif`  | 여러 조건을 순서대로 검사    | 점수, 온도 구간 판정    |
| `and`   | 두 조건이 모두 참        | 정상 온도 범위 검사     |
| `or`    | 둘 중 하나라도 참        | 여러 입력값 허용       |
| `not`   | 참과 거짓을 반대로 변경     | 특정 조건이 아닌 경우    |
| 중첩 `if` | 조건문 안에 조건문 작성     | 큰 조건 안에서 세부 판정  |

---

## 📍 언제 사용하는가?

* 설비 온도를 정상과 경고로 구분할 때
* 점수에 따라 학점을 출력할 때
* 사용자가 입력한 값에 따라 다른 메시지를 출력할 때
* 체온이나 측정값의 구간을 판단할 때
* 여러 조건을 동시에 검사할 때

# 1. 조건문이란?

조건문은 특정 조건에 따라 실행할 코드를 결정한다.

```python
temp = 85

if temp > 80:
    print("경고")
```

`temp > 80`의 결과가 `True`이면 들여쓰기 된 코드가 실행된다.

조건문의 조건식은 반드시 최종적으로 `True` 또는 `False`가 되어야 한다.

```python
print(85 > 80)
```

```text
True
```

---

# 2. `if`문

## 기본 문법

```python
if 조건식:
    실행할 코드
```

예시:

```python
temp = 85

if temp > 80:
    print("🚨 온도가 80도를 초과했습니다.")
    print("관리자에게 알림을 전송합니다.")

print("온도 확인 완료")
```

조건이 참이면 들여쓰기 된 코드가 실행된다.

`print("온도 확인 완료")`는 조건문 밖에 있으므로 항상 실행된다.

## 조건이 거짓인 경우

```python
temp = 50

if temp > 80:
    print("경고")

print("확인 완료")
```

```text
확인 완료
```

조건이 거짓이면 `if`문 내부는 건너뛴다.

---

# 3. `if-else`문

두 가지 결과 중 하나를 실행하고 싶을 때 사용한다.

```python
temp = 70

if temp > 80:
    print("경고")
else:
    print("정상")
```

`if`와 `else`의 코드가 동시에 실행되는 일은 없다.

* 조건이 참이면 `if`
* 조건이 거짓이면 `else`

둘 중 하나만 실행된다.

## 잘못된 구조

```python
temp = 90

if temp > 80:
    print("경고")

print("정상")
```

```text
경고
정상
```

`print("정상")`이 조건문 밖에 있기 때문에 항상 실행된다.

## 올바른 구조

```python
if temp > 80:
    print("경고")
else:
    print("정상")
```

---

# 4. `if-elif-else`문

조건이 세 개 이상일 때 사용한다.

```python
score = 82

if score >= 90:
    print("우수")
elif score >= 70:
    print("보통")
elif score >= 50:
    print("미흡")
else:
    print("비상")
```

위에서부터 조건을 검사하다가 처음으로 참이 된 코드만 실행한다.

```text
보통
```

## 학점 판정

```python
score = int(input("점수를 입력하세요: "))

if score >= 90:
    print("A 학점")
elif score >= 80:
    print("B 학점")
elif score >= 70:
    print("C 학점")
else:
    print("F 학점")
```

# 5. 조건 순서

`if-elif` 구조에서는 조건을 작성하는 순서가 중요하다.

## 잘못된 순서

```python
score = 100

if score >= 50:
    print("미흡")
elif score >= 70:
    print("보통")
elif score >= 90:
    print("우수")
```

```text
미흡
```

첫 번째 조건인 `score >= 50`이 이미 참이므로 아래 조건은 검사하지 않는다.

## 올바른 순서

```python
score = 100

if score >= 90:
    print("우수")
elif score >= 70:
    print("보통")
elif score >= 50:
    print("미흡")
else:
    print("비상")
```

```text
우수
```

> 숫자 구간을 판정할 때는 보통 큰 기준부터 작은 기준 순서로 작성한다.

# 6. 논리 연산자

## 6.1 `and`

두 조건이 모두 참이어야 한다.

```python
temp = 36.5

if temp >= 36.2 and temp <= 36.9:
    print("정상 체온")
```

| 첫 번째 조건 | 두 번째 조건 | 결과      |
| ------- | ------- | ------- |
| `True`  | `True`  | `True`  |
| `True`  | `False` | `False` |
| `False` | `True`  | `False` |
| `False` | `False` | `False` |

### 범위 조건 간단히 작성하기

```python
if 36.2 <= temp <= 36.9:
    print("정상 체온")
```

파이썬에서는 이 방식이 더 읽기 쉽다.

---

## 6.2 `or`

둘 중 하나라도 참이면 전체 결과가 참이다.

```python
color = input("신호등 색: ")

if color == "초록색" or color == "빨간색":
    print("정상 입력")
else:
    print("다시 입력하세요")
```

| 첫 번째 조건 | 두 번째 조건 | 결과      |
| ------- | ------- | ------- |
| `True`  | `True`  | `True`  |
| `True`  | `False` | `True`  |
| `False` | `True`  | `True`  |
| `False` | `False` | `False` |

---

## 6.3 `not`

참과 거짓을 반대로 바꾼다.

```python
print(not True)
print(not False)
```

```text
False
True
```

예시:

```python
if not (3 == 5):
    print("실행됨")
```

`3 == 5`는 `False`이지만 `not`이 붙어 `True`로 바뀐다.

# 7. 중첩 조건문

조건문 안에 또 다른 조건문을 작성할 수 있다.

```python
color = input("신호등 색: ")

if color == "초록색" or color == "빨간색":
    if color == "초록색":
        print("건너세요")
    else:
        print("기다리세요")
else:
    print("잘못된 입력입니다.")
```

## 동작 흐름

1. 입력값이 초록색 또는 빨간색인지 검사한다.
2. 정상 입력이라면 다시 색상을 검사한다.
3. 초록색이면 건넌다.
4. 빨간색이면 기다린다.

## 주의점

중첩이 많아지면 코드가 읽기 어려워질 수 있다.

가능하면 `elif`로 간단히 표현할 수 있는지 먼저 확인한다.

```python
if color == "초록색":
    print("건너세요")
elif color == "빨간색":
    print("기다리세요")
else:
    print("잘못된 입력입니다.")
```

# 8. 범위 조건 작성하기

체온처럼 여러 구간을 판정할 때는 경계값을 정확히 정해야 한다.

```python
temp = float(input("체온을 입력하세요: "))

if temp < 36.2:
    print("저체온")
elif temp <= 36.9:
    print("정상 체온")
elif temp < 37.8:
    print("미열")
else:
    print("고온")
```

## 구간

| 조건                     | 판정  |
| ---------------------- | --- |
| `temp < 36.2`          | 저체온 |
| `36.2 <= temp <= 36.9` | 정상  |
| `36.9 < temp < 37.8`   | 미열  |
| `temp >= 37.8`         | 고온  |

앞에서 이미 거짓으로 판정된 조건은 뒤에서 다시 작성하지 않아도 된다.

```python
elif temp <= 36.9:
```

이 시점에는 이미 `temp < 36.2`가 거짓이므로 자동으로 `36.2 이상`이다.

# 9. 자주 하는 실수

## 9.1 콜론을 빠뜨리는 경우

잘못된 코드:

```python
# if temp > 80
#     print("경고")
```

올바른 코드:

```python
if temp > 80:
    print("경고")
```

---

## 9.2 들여쓰기가 맞지 않는 경우

```python
if temp > 80:
    print("경고")
    print("관리자 호출")
```

조건문에 속하는 코드는 같은 깊이로 들여쓰기 해야 한다.

---

## 9.3 비교 연산자와 할당 연산자 혼동

```python
temp = 80
```

값을 저장하는 할당이다.

```python
temp == 80
```

두 값이 같은지 비교한다.

---

## 9.4 경계값을 중복하거나 빠뜨리는 경우

```python
if temp <= 36.2:
    print("저체온")
elif temp >= 36.2:
    print("정상")
```

`36.2`가 두 조건에 모두 포함된다.

조건 구간을 명확하게 나눈다.

```python
if temp < 36.2:
    print("저체온")
else:
    print("정상 이상")
```

---

## 9.5 조건 순서가 잘못된 경우

```python
if score >= 50:
    print("미흡")
elif score >= 90:
    print("우수")
```

넓은 조건을 먼저 쓰면 뒤의 세부 조건이 실행되지 않는다.

# 10. 이해도 점검

## 퀴즈

다음 코드의 출력 결과를 예상해보자.

```python
temp = 92

if temp >= 100:
    print("위험")
elif temp >= 90:
    print("경고")
elif temp >= 80:
    print("주의")
else:
    print("정상")
```

## 실습

사용자에게 설비 온도를 입력받아 다음 기준으로 상태를 출력해보자.

| 온도     | 출력          |
| ------ | ----------- |
| 100 이상 | `위험: 즉시 정지` |
| 90 이상  | `경고: 점검 필요` |
| 80 이상  | `주의`        |
| 80 미만  | `정상`        |

조건:

* 입력값은 `float`로 변환한다.
* `if-elif-else`를 사용한다.
* 높은 온도 조건부터 작성한다.
