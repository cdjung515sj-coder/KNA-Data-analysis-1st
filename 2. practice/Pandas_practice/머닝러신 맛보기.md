# 머닝러신

1. 머신러닝의 핵심 개념과 학습 방식
 * 지도학습 (Supervised Learning)
   * 개념: 사람이 미리 정리해 놓은 데이터(정답/교과서)와 규칙을 기반으로 AI를 학습시키는 방식입니다.
   * 자율주행 적용 예시: 과거 규칙 기반(Rule-based) 자율주행 기술입니다. 미리 교통법규, 차선 인식 기준 등을 코드로 입력하여 정해진 규칙에 따라 작동합니다. (예: ADAS 차선 유지 장치)
   * 한계: 미리 정의하지 않은 예외 상황이나 이상치(Outlier) 등 세상의 모든 경우의 수를 사람이 일일이 커버할 수 없음을 확인했습니다. (초기 번역기 서비스가 자주 오역을 냈던 이유와 동일)

 * 비지도학습 (Unsupervised Learning)
   * 개념: 사람이 정답을 알려주지 않고, 방대한량의 데이터를 AI에 주어 AI 스스로 그 안에서 규칙과 패턴을 찾게 만드는 방식입니다.
   * 자율주행 적용 예시: 테슬라의 엔드투엔드(End-to-End) 자율주행 방식입니다. 차량 센서/카메라 데이터를 수집하여 서버로 보낸 뒤, AI가 데이터 학습을 통해 "빨간 불이 위에 보이면 차들이 멈춘다"라는 규칙을 스스로 발견하게 합니다.
   * 특징: 극도로 방대한 데이터를 처리해야 하므로 초고성능 데이터센터/슈퍼컴퓨터와 막대한 전력이 소요됩니다.

2. 생성형 AI (LLM)와 파인튜닝 (Fine-Tuning)
 * LLM의 기본 동작 원리 (비지도학습 기반)
   * 웹상의 방대한 텍스트 데이터를 수집하여 **"이 단어 다음에 어떤 단어가 나올 확률이 가장 높은가?"**를 계산해 자연스러운 문장을 생성합니다.

 * 할루시네이션(거짓말) 발생 원인
   * 모델은 사실관계를 판단하기보다 '확률적으로 그럴듯한 문장'을 완성하려는 특성이 있어, 모르는 내용도 마치 사실인 것처럼 지어내는 문제가 발생합니다. (예: 세종대왕 맥북 던짐 사건)

 * 파인튜닝 (Fine-Tuning, 지도학습과의 결합)
   * 비지도학습으로 구축된 LLM에 지도학습(사람의 피드백 및 규칙 부여)을 적용하여 모델을 정교화하는 과정입니다.
   * 정답과 오답을 가려내어 할루시네이션을 줄이고 정확도를 높입니다. (초기 OpenAI는 데이터 라벨링을 위해 인건비가 저렴하고 영어가 통하는 케냐의 인력을 활용함)
> 핵심 시사점: 현대 AI 발전은 비지도학습과 지도학습이 서로의 한계를 보완하며 결합하여 이루어지고 있습니다.

3. 데이터 분석과 이상치(Outlier) 처리
머신러닝이나 AI에만 모든 것을 의존할 수는 없으며, 데이터를 다루는 분석가는 기본적인 데이터 정제 및 도메인 지식을 갖추어야 합니다.

이상치 처리 3단계 워크플로우
 * 탐색 (Search): IQR 등 통계적 기법이나 모델을 활용해 정상 범위를 벗어난 이상치 데이터의 위치를 탐색합니다.
 * 판단 (Decision): 센서 고장인지, 단순 실투/오류인지, 실제 사고·특이상황 발생인지 판단합니다.
   * 주의 사항: 분석가가 임의로 건너뛰거나 판단해서는 안 되며, 현장 담당자와의 **소통(도메인 지식)**을 통해 결정해야 합니다.

 * 처리 (Action): 제거, 수정, 결측 변환 등 원래 신호를 최대한 보존하는 방식으로 처리합니다.

기록과 관리의 중요성
 * 데이터는 지속해서 쌓이므로 이상치 처리는 일회성 작업이 아닙니다.
 * 처리 이유와 코드를 문서화하고 기록으로 남겨야 유사 상황 재발 시 대응이 가능하며, 다른 담당자에게 업무가 이관되어도 지속성을 유지할 수 있습니다. (조선왕조실록의 기상/지진 기록이 후대에 가치 있게 활용되는 것과 같은 맥락)

4. 통계 기반 이상치 탐지 기법: IQR과 분포
 * 데이터를 바라보는 두 가지 축
   * 중심: 데이터가 어디에 모여 있는가? (평균, 중앙값)
   * 퍼짐(산포도): 중심으로부터 얼마나 흩어져 있는가? (범위, 표준편차, IQR)

 * 범위(Range = Max - Min)의 한계
   * 최고값과 최저값의 차이로 계산되는 범위는 구현이 단순하지만, 단 하나의 극단적인 값(이상치)에 매우 취약하여 전체 정상 데이터의 폭을 왜곡시킬 수 있습니다.

 * IQR (Interquartile Range, 사분위수 범위)
   * 평균이나 범위(Range)가 가진 이상치에 대한 약점을 극복하기 위해 사용하는 **통계 기반 접근법(IQR)**입니다.
   * 전체 데이터를 크기순으로 정렬한 뒤 중앙부 데이터 분포(사분위수)를 활용해 정상 범위와 이상치를 안정적으로 정의합니다.
