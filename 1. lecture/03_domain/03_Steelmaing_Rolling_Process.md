# 1. 제강과 정련

## 1-1. 제강의 본질

제강의 핵심은 **용선 속의 탄소와 불순물을 제거하여 원하는 성분의 강을 만드는 것**이다.

주요 제거 성분:

| 성분 | 문제가 되는 이유 | 제거 방식 |
|---|---|---|
| 탄소(C) | 과다하면 취성 증가 | 산소와 반응 → CO/CO₂ 기체 |
| 인(P) | 저온 취성 유발 | 슬래그로 이동 |
| 황(S) | 고온 균열 유발 | 슬래그로 이동 |

### [추가 개념] 제선과 제강 차이

- **제선**: 철광석에서 철 성분을 뽑아 **용선**을 만드는 공정
- **제강**: 용선의 탄소·불순물을 줄이고 성분을 맞춰 **용강**을 만드는 공정

즉,

```text
제선 = 철을 만든다
제강 = 철을 강으로 품질 조정한다
```

---

## 1-2. 전로(Basic Oxygen Furnace)

전로는 용선에 **고순도 산소를 강하게 불어 넣어** 탄소와 불순물을 제거하는 설비이다.

### 전로 1회 작업 흐름

```text
STEP 1. 장입
고철 투입 → 용선 투입

STEP 2. 취련·측정
산소 취입 → 불순물 제거 → 성분·온도 측정

STEP 3. 출강·배재
용강 → 래들
슬래그 → 별도 배출
```

### 핵심 용어

- **취련**: 전로 내부에 산소를 불어 탄소·불순물을 제거하는 작업
- **출강**: 전로의 용강을 밖으로 빼내는 것
- **배재**: 슬래그를 제거하는 것
- **래들(Ladle)**: 용강을 운반하고 필요 시 정련도 수행하는 대형 용기
- **랜스(Lance)**: 전로 내부에 산소를 취입하는 긴 관
- **슬래그(Slag)**: 불순물이 산화되어 모인 비금속성 물질

### [추가 개념] 왜 고철을 먼저 넣을까?

전로 반응은 매우 큰 열을 발생시킨다.  
고철은 이 열을 흡수하면서 녹기 때문에 **온도를 조절하는 역할**도 한다.

---

## 1-3. 취련 상태를 파악하는 신호

전로 내부를 직접 보기 어렵기 때문에 여러 **간접 신호**를 이용한다.

| 신호 | 의미 |
|---|---|
| 배가스 성분 | 탈탄 반응 진행도 추정 |
| 랜스 진동·소리 | 반응 격렬도 파악 |
| 시료 성분 분석 | 목표 성분 도달 여부 |
| 온도 | 출강 가능 여부 판단 |

### 데이터 분석에서 중요한 이유

한 가지 센서만 보면 상태를 잘못 판단할 수 있다.

예:

```text
배가스 + 랜스 진동 + 온도 + 성분 분석
                ↓
        취련 상태 종합 판단
```

즉, 제조 데이터에서는 **다변량 분석**이 중요하다.

---

## 1-4. 배치 데이터와 사이클 정렬

전로는 같은 작업을 여러 번 반복하는 **배치 공정**이다.

각 작업의 실제 시작 시간이 다르므로 단순 시각 기준으로 비교하면 패턴이 섞일 수 있다.

```text
실제 시각
A 배치: 10:03 시작
B 배치: 10:51 시작
C 배치: 11:40 시작
```

이들을 모두:

```text
취련 시작 = 0분
```

으로 맞추면 비교가 쉬워진다.

### [추가 개념] 사이클 정렬(Cycle Alignment)

배치형 공정 분석에서 매우 중요한 전처리이다.

```text
절대 시각 → 상대 시각
2026-08-01 10:03:10 → 취련 후 0초
2026-08-01 10:04:10 → 취련 후 60초
```

이렇게 하면:

- 정상 배치 평균 패턴 계산
- 이상 배치와 정상 배치 비교
- 특정 시점의 이상 징후 탐색

이 가능해진다.

## 1-5. 전로 설비 감시 항목

### 노체 경동 장치

수백 톤 규모의 전로를 기울이는 설비.

주요 관측값:

- 구동 전류
- 유압 압력
- 위치·각도
- 정지 위치 오차

### 랜스 승강 장치

산소 랜스의 높이를 조절한다.

주요 관측값:

- 랜스 높이
- 냉각수 유량
- 냉각수 입·출구 온도
- 구동 전류
- 진동

### [추가 개념] 전류가 왜 중요한가?

모터가 더 큰 힘을 내야 할수록 일반적으로 전류가 증가한다.

예:

```text
정상 상태
모터 전류 = 80 A

마찰 증가 / 축 정렬 이상 / 베어링 열화
→ 더 큰 토크 필요
→ 모터 전류 = 95 A
```

따라서 **같은 운전 조건에서 전류가 계속 증가하면 설비 열화 신호**일 수 있다.

# 2. 2차 정련

전로에서 나온 용강 성분과 온도를 목표 규격에 정밀하게 맞추는 작업을 거침 

전로가 불순물을 대량 제거하는 1차 정련((불순물 슬래그로 제거)), 래들에서 성분.온도를 규격에 맞추는 것이 2차 정련이라고 함.


전로에서 나온 용강을 **최종 규격에 더 정확하게 맞추는 과정**이다.

## 2-1. 2차 정련의 주요 역할

1. 성분 미세 조정  - 합금 원소를 목표량에 맞춰 첨가
2. 온도 조정  - 연주 토입 온도에 맞춰 승온, 유지
3. 황·질소·수소 등 유해 성분 제거  - 황, 질소, 수소를 추가 저감
4. 개재물 제거  - 미세 산화물을 띄워 슬래그로 회수

### [추가 개념] 개재물(Inclusion)

강 내부에 남아 있는 비금속성 미세 입자.

예:

- 산화물
- 황화물

개재물이 많으면:

- 균열 발생 가능성 증가
- 표면 품질 저하
- 피로 수명 저하

---

## 2-2. LF와 RH

### LF (Ladle Furnace)

주요 기능:

- 전극 가열
- 가스 교반
- 승온
- 성분 조정
- 탈황

### RH (Ruhrstahl-Heraeus)

주요 기능:

- 진공 처리
- 수소 제거
- 질소 제거

### 비교

| 설비 | 핵심 기능 |
|---|---|
| LF | 가열 + 성분 조정 + 탈황 |
| RH | 진공 탈가스 |

---

## 2-3. 정련 시간과 생산 스케줄

RH 진공 탈가스 등은 **강종별**로 일정 처리 시간이 필요하다.

정련이 지연되면:

```text
정련 지연
   ↓
래들 도착 지연
   ↓
연주 대기
   ↓
용강 온도 하락
   ↓
품질 / 생산성 문제
```

### [추가 개념] 센서 데이터만 보면 안 되는 이유

모든 원인이 센서에 직접 기록되는 것은 아니다.

예:

- 대기시간
- 작업 지연
- 설비 교체
- 작업자 조치
- 정비 기록

따라서 설비 분석에서는 **센서 + 조업 로그 + 정비 이력**을 함께 봐야 한다.

---

## 2-4. 래들 관리

### 내화물

약 1600℃ 용강에 반복 노출되며 마모된다.

관리 변수:

- 사용 횟수
- 보수 이력
- 내화물 두께
- 사용 시간

### 예열 상태

래들이 충분히 예열되지 않으면 용강이 래들에 들어온 뒤 온도가 더 많이 떨어질 수 있다.

### 슬라이드 게이트

래들 바닥의 유압식 개폐 장치.

이상이 발생하면:

- 누출
- 유량 이상
- 개폐 불량

# 3. 연속주조

## 3-1. 연속주조란?

제강에서 만든 용강을 연속적으로 응고시켜 반제품으로 만드는 공정.

대표 반제품:

- 슬래브(Slab)
- 블룸(Bloom)
- 빌릿(Billet)

---

## 3-2. 연속주조의 핵심 — 응고 껍질

몰드에서 처음부터 전체가 굳는 것이 아니다.

```text
외부 → 먼저 굳음
내부 → 아직 액체
```

즉,

```text
[고체 껍질]
[액체 중심부]
```

형태로 아래 방향으로 이동한다.

### 대표 사고: 브레이크아웃(Breakout)

응고 껍질이 찢어지면 내부 용강이 밖으로 유출되는 사고.

영향:

- 설비 손상
- 생산 중단
- 장시간 복구

---

## 3-3. 응고 3단계

### 1단계: 몰드 응고

몰드 벽과 접촉하면서 초기 응고 껍질 형성

### 2단계: 2차 냉각

물 분사 + 롤 지지

→ 응고 껍질이 내부로 성장

### 3단계: 완전 응고·절단

중심부까지 응고 완료 후 목표 길이로 절단

---

## 3-4. 주조 속도

교재 기준 일반 주조 속도:

```text
약 0.5 ~ 2.0 m/min
```

### 속도가 빠르면

장점:

- 생산량 증가

단점:

- 몰드 체류 시간 감소
- 응고 껍질이 얇아질 가능성
- 브레이크아웃 위험 증가

### 속도가 느리면

장점:

- 응고 시간 확보
- 안전 여유 증가

단점:

- 생산량 감소
- 과도한 저속 운전에 따른 부작용 가능

### 핵심

```text
생산성 ↑  ↔  안전성 ↑
```

둘 사이의 균형이 중요하다.

---

## 3-5. 연주기 설비 흐름

```text
래들
 ↓
턴디시
 ↓
침지 노즐
 ↓
몰드
 ↓
2차 냉각대
 ↓
핀치롤
 ↓
절단
```

### 각 설비 역할

| 설비 | 역할 |
|---|---|
| 래들 | 용강 공급 |
| 턴디시 | 용강 저장·완충·분배 |
| 침지 노즐 | 용강을 몰드로 공급 |
| 몰드 | 초기 응고 껍질 형성 |
| 2차 냉각대 | 냉각 및 응고 진행 |
| 핀치롤 | 주편 인출 및 지지 |

---

## 3-6. 주요 감시 항목

### 턴디시

- 용강 무게
- 온도
- 래들 교체 시점

### 몰드

- 몰드 레벨
- 냉각수 온도차
- 벽면 다지점 온도

### 2차 냉각대

- 구간별 냉각수 유량
- 인출 속도

### [추가 개념] 몰드 레벨이 중요한 이유

몰드 안 용강 높이가 크게 흔들리면:

```text
유량 불안정
 ↓
응고 조건 변화
 ↓
껍질 두께 불균일
 ↓
표면 결함 또는 브레이크아웃 위험
```

이 증가할 수 있다.

# 4. 연주 설비의 분석 난점

## 4-1. 롤이 너무 많다

연주기에는 수십~수백 개의 롤이 존재할 수 있다.

문제:

- 모든 롤에 센서 설치 어려움
- 센서 유지보수 비용 증가
- 고온 환경
- 운전 중 접근 어려움

따라서 일부 설비는 **직접 센싱보다 간접 신호**를 활용해야 한다.

예:

```text
롤 고착
→ 인출 부하 증가
→ 모터 전류 변화
→ 표면 자국
```

---

## 4-2. 대표 사고와 품질 문제

| 문제 | 설명 |
|---|---|
| 브레이크아웃 | 응고 껍질 파단 → 용강 유출 |
| 표면 결함 | 균열, 오실레이션 자국 등 |
| 노즐 막힘 | 유량 편차 → 몰드 레벨 변동 → 응고 불균일 |

---

## 4-3. 원인 시점과 발견 시점이 다르다

제조 데이터에서 매우 중요한 문제이다.

### 즉시 사고

브레이크아웃처럼 사고 발생 시점이 비교적 명확하다.

```text
사고 직전 수분~수십초 신호
→ 고장 예측
```

### 지연 결함

표면 결함처럼 나중 공정에서 발견되는 경우가 있다.

```text
연주에서 원인 발생
       ↓
압연
       ↓
검사에서 결함 발견
```

이 경우 **라벨 시점과 원인 시점이 다르다.**

### [추가 개념] 라벨 지연(Label Delay)

머신러닝에서:

```text
센서 데이터 시점 ≠ 품질 판정 시점
```

인 상황.

이때 단순히 검사 시점 주변 센서를 쓰면 실제 원인을 놓칠 수 있다.

# 5. 제강 배치와 연주 시계열 연결

## 5-1. 제강 데이터

보통:

```text
1행 = 1차지(Charge)
```

형태의 배치 데이터.

### 차지(Charge)

전로에서 한 번에 정련한 용강 한 배치.

또는:

- Heat
- 히트

라고도 부른다.

---

## 5-2. 연주 데이터

연주는 초 단위로 센서가 기록되는 **시계열 데이터**이다.

```text
timestamp
10:00:00
10:00:01
10:00:02
...
```

여러 차지가 연속으로 연결된다.

---

## 5-3. 턴디시 혼합 구간

래들이 바뀌는 순간 용강이 정확히 딱 나뉘는 것이 아니다.

기존 차지와 새로운 차지가 잠시 섞일 수 있다.

따라서 경계는:

```text
A 차지 | B 차지
```

처럼 단순한 한 점이 아니라:

```text
A 차지 → 혼합 구간 → B 차지
```

형태가 될 수 있다.

### [추가 개념] 데이터 조인 시 주의

제강 배치 데이터와 연주 시계열을 연결할 때:

- 차지 번호
- 주조 시작·종료 시간
- 턴디시 교체
- 혼합 구간

을 고려해야 한다.

# 6. 압연과 두께 제어

## 6-1. 압연이란?

연주에서 만들어진 슬래브를 롤 사이로 통과시켜 원하는 두께의 강판으로 만드는 공정.

열간압연 전 슬래브는 가열로에서 약:

```text
1,100 ~ 1,250℃
```

까지 다시 가열된다.

---

# 7. 가열로

## 7-1. 가열로 구역

| 구역 | 역할 | 대표 감시값 |
|---|---|---|
| 예열대 | 배가스 열로 초기 가열 | 구역 온도, 배가스 온도 |
| 가열대 | 버너로 목표 온도까지 상승 | 연료 유량, 공기비 |
| 균열대 | 슬래브 안팎 온도차 감소 | 온도, 체류 시간 |

---

## 7-2. 가열로 제어가 어려운 이유

### 1. 열 전달 지연

버너를 조작해도 슬래브 중심 온도는 바로 변하지 않는다.

```text
버너 조작
 ↓
표면 온도 변화
 ↓
시간 지연
 ↓
중심 온도 변화
```

### 2. 상호 간섭

한 슬래브만 독립적으로 존재하는 것이 아니라 여러 슬래브가 같은 가열 환경을 공유한다.

### 3. 조건 의존

필요 열량은 다음에 따라 달라진다.

- 슬래브 두께
- 폭
- 강종
- 초기 온도
- 체류 시간

---

## 7-3. 결과값과 조작량

### 결과값(Control Variable)

맞추고 싶은 값.

예:

```text
슬래브 목표 온도 = 1200℃
```

### 조작량(Manipulated Variable)

목표값을 맞추기 위해 바꾸는 값.

예:

```text
연료 유량
```

### [추가 개념] 제어의 기본 구조

```text
목표값(Set Point)
     ↓
Controller
     ↓
조작량
     ↓
공정
     ↓
측정값
     └──────── 피드백
```

---

# 8. 열화와 연료 사용량

가열로가 열화되어도 제어 시스템이 온도를 계속 목표값에 맞출 수 있다.

그래서 단순히 온도만 보면 정상으로 보일 수 있다.

하지만:

```text
같은 1200℃ 유지
과거 연료 = 100
현재 연료 = 115
```

라면 설비 효율이 나빠졌을 가능성이 있다.

### 핵심 포인트

```text
결과값은 정상인데
조작량이 점점 커진다
→ 초기 열화 신호 가능
```

이 개념은 설비 예지보전에서 매우 중요하다.

---

# 9. 압연의 기본 원리

## 9-1. 롤 갭

두 롤 사이의 간격.

재료보다 좁게 설정하여 재료를 압축한다.

## 9-2. 두께 감소와 길이 증가

압연 과정에서 재료의 부피는 크게 변하지 않는다고 보면:

```text
두께 ↓
길이 ↑
```

가 된다.

## 9-3. 다단 패스

한 번에 목표 두께까지 줄이지 않고 여러 압연기를 거치며 단계적으로 두께를 줄인다.

---

# 10. 열간압연 vs 냉간압연

| 구분 | 열간압연 | 냉간압연 |
|---|---|---|
| 재료 상태 | 고온 | 상온 또는 낮은 온도 |
| 변형 저항 | 낮음 | 높음 |
| 큰 변형 | 쉬움 | 어려움 |
| 표면 | 상대적으로 거침 | 깨끗함 |
| 치수 정밀도 | 낮음 | 높음 |
| 특징 | 큰 폭의 두께 감소 | 정밀 두께·표면 품질 |
| 후속 공정 | 냉각·권취 | 소둔 필요 가능 |

### [추가 개념] 가공 경화

냉간압연처럼 낮은 온도에서 큰 변형을 주면 재료가 단단해지고 연성이 감소할 수 있다.

이를 **가공 경화**라고 한다.

그래서 이후 **소둔(Annealing)**을 통해 조직과 성질을 회복한다.

# 11. 열연 구간별 감시값

## 스케일 제거

고압수로 산화 스케일 제거.

감시:

- 펌프 토출압

## 조압연·마무리 압연

감시:

- 모터 전류
- 유압 실린더 압력
- 압연 하중

## 냉각대·권취

감시:

- 장력
- 라인 속도
- 냉각수 유량
- 권취 속도

# 12. 시간 정렬이 아닌 위치 정렬

열연 라인은 매우 길다.

같은 강판의 앞부분과 뒷부분이 여러 센서를 서로 다른 시각에 통과한다.

따라서 단순히:

```text
timestamp 기준
```

으로 센서를 합치면 같은 위치의 데이터가 어긋날 수 있다.

### 위치 기준 정렬

```text
코일 길이 0 m
코일 길이 10 m
코일 길이 20 m
...
```

기준으로 센서값을 연결한다.

### [추가 개념] 시간 → 위치 변환

속도가 일정하다고 단순화하면:

```text
거리 = 속도 × 시간
```

을 사용할 수 있다.

하지만 실제 라인에서는 속도가 계속 바뀔 수 있으므로 실제 속도 데이터를 이용한 누적 거리 계산이 필요하다.

# 13. 통판 사고

압연 중 강판이 정상적으로 진행되지 않고:

- 접힘
- 뭉침
- 꼬임

등이 발생하는 사고.

결과:

- 생산 중단
- 설비 손상
- 장시간 복구

# 14. 롤 갭·하중·두께 관계

## 롤 갭

운전자가 설정하는 롤 사이 간격.

## 압연 하중

재료가 압연에 저항하면서 발생하는 반력.

## 출측 두께

실제 최종 두께는 단순히 롤 갭과 같지 않다.

이유:

```text
압연 하중
 ↓
압연기 프레임 탄성 변형
 ↓
실제 롤 간격 변화
 ↓
출측 두께 변화
```

### [추가 개념] Mill Stretch

압연 하중 때문에 압연기 자체가 미세하게 늘어나는 현상.

따라서:

```text
설정 롤 갭 ≠ 실제 출측 두께
```

가 될 수 있다.

---

# 15. 재료 조건이 압연 결과에 미치는 영향

슬래브가 목표보다 차가우면:

```text
재료 변형 저항 증가
 ↓
압연 하중 증가
 ↓
두께 증가 가능
```

즉, 두께 문제를 볼 때 롤 갭 설정만 보면 안 되고:

- 온도
- 강종
- 강도
- 압연 속도

도 같이 봐야 한다.

---

# 16. AGC(Automatic Gauge Control)

AGC는 **자동 두께 제어 시스템**이다.

## 제어 흐름

```text
STEP 1
압연 하중 측정

STEP 2
압연기 탄성 변형 계산
→ 롤 갭 선행 보정

STEP 3
출측 두께계 측정
→ 실제 오차에 따라 추가 보정
```

---

## [추가 개념] 선행 제어와 후행 제어

### 선행 제어(Feedforward)

결과가 나오기 전에 원인을 보고 미리 보정.

예:

```text
압연 하중 증가 감지
→ 두께 증가 예상
→ 미리 롤 갭 보정
```

장점:

- 빠른 대응

### 후행 제어(Feedback)

실제 결과 오차를 측정한 뒤 보정.

예:

```text
목표 두께 = 2.00 mm
실측 두께 = 2.05 mm
→ 롤 갭 추가 보정
```

장점:

- 실제 결과 기반 보정

### AGC는 두 방식을 함께 활용

```text
선행 보정 + 실측 후행 보정
```

---

# 17. 설비 열화 조기 탐지

교재에서 중요한 핵심이다.

설비가 열화되더라도 제어 시스템 때문에 **최종 품질은 한동안 정상으로 유지될 수 있다.**

예:

| 변수 | 열화 진행 시 |
|---|---|
| 출측 두께 | 목표 근처 유지 |
| 롤 갭 보정 | 보정 폭 증가 |
| 압연 하중 | 점진적 증가 |
| 주모터 전류 | 같은 조건에서 증가 |

따라서:

```text
하중 / 롤 갭 / 전류
= 조기 경보(선행 신호)

출측 두께 불량
= 최종 결과(후행 신호)
```

### 핵심 데이터 분석 관점

**고장 예측에서는 결과값보다 조작량·부하 변화가 더 일찍 이상을 보여줄 수 있다.**

---

# 18. 권취 장력

압연이 끝난 강판은 코일 형태로 감긴다.

## 장력이 너무 낮으면

- 느슨한 권취
- 층간 밀림
- 코일 형상 붕괴

## 장력이 너무 높으면

- 판 신장
- 표면 자국

### 장력 형성 방법

권취 속도를 라인 속도보다 약간 높게 설정하여 장력을 만든다.

---

# 19. 코일 경계

권취 종료·시작 이벤트는 연속 시계열 데이터를 **코일 단위로 나누는 기준**이 된다.

```text
연속 센서 시계열
 ↓
권취 이벤트 기준 분할
 ↓
Coil 001
Coil 002
Coil 003
```

이것은 분석에서 매우 중요한 **데이터 세그먼테이션**이다.

# 20. 롤 마모와 교체 패턴

롤은 사용할수록 마모된다.

```text
롤 사용
 ↓
마찰 증가
 ↓
압연 하중 점진적 상승
 ↓
롤 교체
 ↓
하중 급격히 하락
 ↓
다시 점진적 상승
```

그래프로 보면 **톱니 모양 패턴**이 나타날 수 있다.

---

## 20-1. 정비 이력이 중요한 이유

정비 기록이 없으면:

```text
하중 급락
```

을 이상으로 잘못 판단할 수 있다.

하지만 실제로는:

```text
롤 교체
→ 정상적인 하중 초기화
```

일 수 있다.

### 핵심

정비 이력은:

1. **라벨**
2. **분석 구간의 경계**
3. **소모품 수명 계산 기준**

역할을 한다.

# 21. 소둔(Annealing)

냉간압연 후 가공 경화된 재료의 성질을 회복시키는 열처리.

## 덮개식 소둔

```text
코일 단위 장시간 가열
→ 배치 데이터
```

## 연속식 소둔

```text
강판을 풀어 연속 통과
→ 시계열 데이터
```

### 핵심

같은 공정 목적이라도 설비 방식에 따라 데이터 구조가 달라진다.

---

# 22. 냉연 공정

대표 흐름:

```text
산세
 ↓
냉간압연
 ↓
세정
 ↓
소둔
 ↓
조질압연
```

## 산세

산을 이용해 열연 코일 표면의 산화 스케일 제거.

## 세정

압연유 등 오염 제거.

## 조질압연

표면·형상 및 기계적 특성을 최종 조정.

---

# 23. 코일 이력 추적

라인별 데이터는 **코일 번호**로 연결해야 한다.

하지만 항상 1:1 관계는 아니다.

예:

```text
원래 코일 1개
→ 절단
→ 코일 2개
```

또는:

```text
코일 A + 코일 B
→ 용접
→ 하나의 연속 라인 데이터
```

따라서:

- 1 : N
- N : 1

관계가 발생할 수 있다.

### [추가 개념] 데이터베이스 관점

단순 `merge()`만 하면 중복이나 누락이 생길 수 있다.

필요한 정보:

- parent coil id
- child coil id
- 절단 위치
- 용접 위치
- 공정 이력

# 24. 아연 도금

## 용융 아연 도금

강판을 용융 아연욕에 침지.

특징:

- 비교적 두꺼운 도금층

## 전기 아연 도금

전기화학적으로 아연을 부착.

특징:

- 얇고 균일한 도금 가능

### 제어 관점

```text
제어 대상 = 도금 두께
조작량 = 공기 압력 등
```

# 25. 정정·검사와 품질 라벨

정정 설비:

- 슬리터
- 절단기
- 교정기
- 검사 설비
- 포장 설비

최종 검사 결과는 상류 공정 분석의 **품질 라벨**로 사용될 수 있다.

하지만 주의:

```text
검사 장치가 결함을 놓치면
→ 실제 불량인데 라벨은 정상
```

일 수 있다.

### [추가 개념] 라벨 노이즈(Label Noise)

# 29. 설비 예지보전에서 자주 만드는 특징(Feature)

원본 센서값 그대로만 쓰는 것이 아니라 변화량과 통계량을 만든다.

## 평균

```python
df["전류"].mean()
```

## 표준편차

```python
df["전류"].std()
```

진동이나 전류의 변동성이 커지는지 확인.

## 이동평균

```python
df["전류_ma"] = df["전류"].rolling(10).mean()
```

노이즈를 줄이고 추세 확인.

## 변화량

```python
df["전류_diff"] = df["전류"].diff()
```

급격한 변화 탐지.

## 변화율

```python
df["전류_pct"] = df["전류"].pct_change()
```

상대적인 증가·감소 확인.

# 30. 이상치와 고장 신호는 다르다

매우 중요하다.

```text
이상치(Outlier)
= 데이터 분포에서 특이한 값

고장 이상(Anomaly)
= 실제 설비 상태가 정상에서 벗어난 현상
```

예:

```text
전류 150A
```

가 통계적으로는 이상치라도 실제로는 정상적인 고부하 작업일 수 있다.

따라서 고장 분석에서는:

- 공정 조건
- 강종
- 속도
- 하중
- 작업 단계

를 함께 고려해야 한다.

# 31. 같은 조건끼리 비교해야 한다

설비 상태 분석의 기본 원칙.

잘못된 비교:

```text
저부하 운전 전류 60A
고부하 운전 전류 90A

→ 90A이므로 고장?
```

이것은 틀릴 수 있다.

올바른 비교:

```text
같은 제품
같은 속도
같은 하중
같은 공정 조건
```

에서:

```text
과거 80A
현재 90A
```

처럼 비교해야 한다.

이를 **조건부 비교**라고 이해하면 좋다.

```text
선행 신호를 이용해 고장을 예측
```

# 35. 시험·복습용 핵심 질문

## 제강

**Q. 제강에서 가장 중요한 제거 대상은?**  
A. 탄소를 포함한 불순물.

**Q. 취련이란?**  
A. 전로에 산소를 불어 탄소와 불순물을 제거하는 작업.

**Q. LF와 RH 차이는?**  
A. LF는 가열·성분 조정·탈황, RH는 진공 탈가스 중심.

---

## 연속주조

**Q. 브레이크아웃이란?**  
A. 응고 껍질이 파단되어 내부 용강이 유출되는 사고.

**Q. 주조 속도가 너무 빠르면?**  
A. 몰드 체류 시간이 줄고 응고 껍질이 얇아져 위험이 증가할 수 있다.

**Q. 차지란?**  
A. 전로에서 한 번에 정련한 용강 한 배치.

---

## 압연

**Q. 압연에서 롤 갭이란?**  
A. 두 롤 사이의 설정 간격.

**Q. AGC란?**  
A. 출측 두께를 목표값에 맞추는 자동 두께 제어 시스템.

**Q. 왜 하중과 전류를 같이 봐야 하나?**  
A. 최종 두께가 정상이어도 설비 열화로 하중·전류가 먼저 증가할 수 있기 때문.

# 36. 헷갈리기 쉬운 개념 비교

## 제선 vs 제강

```text
제선 = 철광석 → 용선
제강 = 용선 → 용강
```

## 전로 vs LF/RH

```text
전로 = 대량 불순물 제거
LF/RH = 정밀 성분·온도 조정
```

## 배치 데이터 vs 시계열 데이터

```text
배치 = 한 작업당 한 행
시계열 = 시간마다 여러 행
```

## 롤 갭 vs 출측 두께

```text
롤 갭 = 설정값
출측 두께 = 실제 결과
```

## 선행 제어 vs 후행 제어

```text
선행 = 결과 전에 미리 보정
후행 = 결과 측정 후 보정
```

## 이상치 vs 고장

```text
이상치 = 통계적으로 특이한 값
고장 = 실제 설비 이상 상태
```

# 37. 가장 중요하게 기억할 흐름

```text
설비 열화
 ↓
마찰 / 저항 증가
 ↓
하중 증가
 ↓
모터 전류 증가
 ↓
제어 시스템이 보정
 ↓
롤 갭 / 연료 / 압력 등 조작량 증가
 ↓
한동안 결과 품질은 정상
 ↓
보정 한계 초과
 ↓
품질 이상 또는 설비 고장
```

즉,

> **설비 고장 예측에서는 최종 결과만 보는 것이 아니라,  
> 결과를 정상으로 유지하기 위해 얼마나 많은 보정을 하고 있는지를 보는 것이 중요하다.**
