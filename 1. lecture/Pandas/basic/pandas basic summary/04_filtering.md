# Pandas 필터링 정리

Pandas에서 **필터링(filtering)** 이란,

> DataFrame의 여러 행 중에서 **내가 원하는 조건을 만족하는 행만 골라내는 것**

입니다.

예를 들어 다음과 같은 데이터가 있다고 해봅시다.

```python
import pandas as pd

df = pd.DataFrame({
    "설비": ["모터", "펌프", "밸브", "모터"],
    "온도": [70, 85, 95, 60],
    "상태": ["정상", "주의", "고장", "정상"]
})
```

| index | 설비 | 온도 | 상태 |
|---:|---|---:|---|
| 0 | 모터 | 70 | 정상 |
| 1 | 펌프 | 85 | 주의 |
| 2 | 밸브 | 95 | 고장 |
| 3 | 모터 | 60 | 정상 |

여기서 다음과 같은 작업이 모두 **필터링**입니다.

- 온도가 80 이상인 행 찾기
- 상태가 고장인 행 찾기
- 설비가 모터 또는 펌프인 행 찾기
- 온도가 높고 상태도 위험한 행 찾기

---

# 1. 불린 인덱싱 Boolean Indexing

## 핵심 개념

불린 인덱싱은 Pandas 필터링의 **가장 기본적인 원리**입니다.

> 각 행에 대해 조건을 검사한 뒤, 결과가 `True`인 행만 가져오는 방식

여기서 Boolean은 다음 두 값을 의미합니다.

```text
True
False
```

---

## 조건식은 먼저 True / False를 만든다

```python
df["온도"] >= 80
```

이 코드는 행을 바로 가져오는 것이 아니라, 각 행이 조건을 만족하는지 검사합니다.

결과:

```text
0    False
1     True
2     True
3    False
```

왜 이렇게 되는지 보면:

```text
70 >= 80 → False
85 >= 80 → True
95 >= 80 → True
60 >= 80 → False
```

즉, Pandas는 각 행에 대해 조건을 검사합니다.

---

## Boolean Series

조건식의 결과처럼 `True`, `False`로 구성된 Series를 **Boolean Series**라고 생각하면 됩니다.

```python
condition = df["온도"] >= 80
print(condition)
```

결과:

```text
0    False
1     True
2     True
3    False
```

필터링의 핵심은 먼저 이런 **True / False 조건표를 만드는 것**입니다.

---

## 실제 행 가져오기

Boolean Series를 DataFrame의 대괄호 안에 넣으면 `True`인 행만 선택됩니다.

```python
df[condition]
```

보통은 한 번에 이렇게 작성합니다.

```python
df[df["온도"] >= 80]
```

결과:

| 설비 | 온도 | 상태 |
|---|---:|---|
| 펌프 | 85 | 주의 |
| 밸브 | 95 | 고장 |

동작 과정:

```text
조건 만들기
    ↓
True / False 생성
    ↓
True인 행만 선택
```

---

## 비교 연산자

불린 인덱싱에서는 비교 연산자를 자주 사용합니다.

| 연산자 | 의미 |
|---|---|
| `>` | 초과 |
| `<` | 미만 |
| `>=` | 이상 |
| `<=` | 이하 |
| `==` | 같다 |
| `!=` | 다르다 |

예:

```python
df[df["온도"] >= 80]
```

온도 80 이상인 행

```python
df[df["상태"] == "고장"]
```

상태가 고장인 행

```python
df[df["설비"] != "모터"]
```

설비가 모터가 아닌 행

---

## 여러 조건 연결하기

### AND : `&`

두 조건을 모두 만족해야 합니다.

```python
df[
    (df["온도"] >= 80) &
    (df["상태"] == "고장")
]
```

의미:

```text
온도 >= 80
그리고
상태 == 고장
```

### OR : `|`

둘 중 하나만 만족해도 됩니다.

```python
df[
    (df["온도"] >= 80) |
    (df["상태"] == "고장")
]
```

### NOT : `~`

조건을 반대로 만듭니다.

```python
df[~(df["상태"] == "고장")]
```

의미:

> 상태가 고장이 아닌 행

---

## `and`, `or`가 아니라 `&`, `|`

일반 Python에서는 다음을 많이 사용합니다.

```python
and
or
not
```

하지만 Pandas에서는 여러 행의 Boolean 값을 각각 비교해야 하므로 다음 연산자를 사용합니다.

| 의미 | Pandas |
|---|---|
| 그리고 | `&` |
| 또는 | `|` |
| 아니다 | `~` |

그리고 여러 조건을 사용할 때는 **조건마다 괄호를 붙이는 습관**이 중요합니다.

```python
(df["온도"] >= 80)
```

---

# 2. `query()`

## 핵심 개념

`query()`도 조건을 만족하는 행을 가져오는 필터링 방법입니다.

차이는 **조건을 작성하는 방식**입니다.

불린 인덱싱:

```python
df[df["온도"] >= 80]
```

`query()`:

```python
df.query("온도 >= 80")
```

둘의 목적은 같습니다.

---

## `query()`의 특징

조건이 길어지면 불린 인덱싱은 다음처럼 복잡해질 수 있습니다.

```python
df[
    (df["온도"] >= 80) &
    (df["진동"] >= 5) &
    (df["압력"] <= 100)
]
```

`query()`를 사용하면 다음처럼 작성할 수 있습니다.

```python
df.query("온도 >= 80 and 진동 >= 5 and 압력 <= 100")
```

즉,

> `query()`는 조건식을 사람이 읽는 문장처럼 작성하기 쉽게 해주는 필터링 방법

이라고 이해하면 됩니다.

---

## 기본 구조

```python
df.query("조건")
```

예:

```python
df.query("온도 >= 80")
```

조건식은 문자열 `" "` 안에 작성합니다.

---

## 문자열 값 비교하기

```python
df.query("상태 == '고장'")
```

바깥 문자열이 큰따옴표이므로, 내부의 `"고장"`은 작은따옴표를 사용하면 편합니다.

---

## 여러 조건

```python
df.query("온도 >= 80 and 상태 == '고장'")
```

또는 OR 조건:

```python
df.query("온도 >= 80 or 상태 == '고장'")
```

---

## 외부 변수 사용하기: `@`

Python 변수의 값을 `query()` 안에서 사용하려면 변수 이름 앞에 `@`를 붙입니다.

```python
limit = 80

df.query("온도 >= @limit")
```

여기서 `@limit`은:

> query 문자열 밖에 있는 Python 변수 `limit`을 사용한다.

는 뜻입니다.

---

## 불린 인덱싱과 `query()`의 관계

```python
df[df["온도"] >= 80]
```

```python
df.query("온도 >= 80")
```

두 방법은 같은 목적을 수행합니다.

정리하면:

- 불린 인덱싱: Pandas의 기본적인 조건 필터링 방식
- `query()`: 조건을 더 읽기 쉽게 표현할 수 있는 방식

---

# 3. `isin()`

## 핵심 개념

`isin()`은 값이 **여러 후보 중 하나에 포함되는지 검사하는 메서드**입니다.

정확히 말하면 `isin()` 자체는 행을 바로 가져오는 것이 아니라,

> 각 값이 목록 안에 포함되어 있는지를 검사해서 `True / False`를 만들어줍니다.

---

## 기본 사용법

```python
df["상태"].isin(["고장", "주의"])
```

의미:

> 상태가 `"고장"` 또는 `"주의"` 중 하나인가?

결과:

```text
0    False
1     True
2     True
3    False
```

즉, `isin()`도 **Boolean Series를 생성합니다.**

---

## 불린 인덱싱과 함께 사용

실제 행을 가져오려면:

```python
df[df["상태"].isin(["고장", "주의"])]
```

동작 과정:

```text
df["상태"].isin(["고장", "주의"])
                ↓
        True / False 생성
                ↓
df[Boolean Series]
                ↓
        True인 행 선택
```

따라서 `isin()`은 완전히 독립된 필터링 방법이라기보다,

> **불린 인덱싱에서 사용할 조건을 만들어주는 메서드**

라고 이해하면 더 정확합니다.

---

## 왜 `isin()`을 사용하는가?

여러 값을 OR 조건으로 비교하면 코드가 길어집니다.

```python
(df["상태"] == "고장") |
(df["상태"] == "주의") |
(df["상태"] == "점검")
```

`isin()`을 사용하면:

```python
df["상태"].isin(["고장", "주의", "점검"])
```

처럼 간단해집니다.

즉,

> 여러 값 중 하나인지 확인할 때 `isin()`을 사용합니다.

---

## `~isin()`

`~`는 True와 False를 반대로 만듭니다.

```python
df["상태"].isin(["고장", "주의"])
```

결과가:

```text
False
True
True
False
```

라면,

```python
~df["상태"].isin(["고장", "주의"])
```

결과는:

```text
True
False
False
True
```

가 됩니다.

그래서:

```python
df[~df["상태"].isin(["고장", "주의"])]
```

는 다음 의미입니다.

> 상태가 고장이나 주의가 아닌 행

---

## 다른 조건과 함께 사용

```python
df[
    (df["상태"].isin(["고장", "주의"])) &
    (df["온도"] >= 80)
]
```

의미:

> 상태가 고장 또는 주의이면서, 온도가 80 이상인 행

---

# 4. 세 방법의 관계

세 가지를 따로 외우기보다는 아래처럼 연결해서 이해하는 것이 좋습니다.

```text
                Pandas 필터링
                     │
         ┌───────────┴───────────┐
         │                       │
   불린 인덱싱                 query()
         │                  조건을 문자열로 작성
         │
         ↓
   Boolean Series
  True / False 생성
         │
         ├── 비교 연산
         │   >=, <=, == ...
         │
         ├── 여러 조건
         │   &, |, ~
         │
         └── isin()
             여러 값 중 포함 여부 검사
```

특히 `isin()`은 다음 흐름으로 이해하면 됩니다.

```text
isin()
  ↓
True / False 생성
  ↓
불린 인덱싱에서 사용
```

---

# 5. 세 방법 비교

| 방법 | 핵심 개념 | 대표 사용 상황 |
|---|---|---|
| **불린 인덱싱** | Boolean Series에서 `True`인 행을 선택 | 일반적인 조건 필터링 |
| **`query()`** | 조건식을 문자열 형태로 작성 | 조건이 길거나 읽기 쉽게 쓰고 싶을 때 |
| **`isin()`** | 여러 후보 값에 포함되는지 `True / False` 반환 | 여러 범주 값 선택 |

---

# 6. 대표 예제

## 온도 80 이상

```python
df[df["온도"] >= 80]
```

## 같은 조건을 `query()`로

```python
df.query("온도 >= 80")
```

## 상태가 고장 또는 주의

```python
df[df["상태"].isin(["고장", "주의"])]
```

## 상태가 고장 또는 주의가 아닌 행

```python
df[~df["상태"].isin(["고장", "주의"])]
```

---

# 7. 핵심 정리

### 1. 필터링

> DataFrame에서 조건을 만족하는 행만 골라내는 작업

### 2. 불린 인덱싱

> 각 행에 대해 조건을 검사해서 `True / False`를 만들고, `True`인 행만 선택

### 3. `query()`

> 불린 인덱싱과 같은 목적의 필터링을 조건 문자열로 더 읽기 쉽게 표현

### 4. `isin()`

> 여러 값 중 하나에 포함되는지 검사해서 Boolean Series를 만드는 메서드

---

# 8. 추천 학습 순서

```text
불린 인덱싱
    ↓
Boolean Series
    ↓
비교 연산자
    ↓
여러 조건 &, |, ~
    ↓
query()
    ↓
isin()
```

이 순서로 이해하면 Pandas 필터링의 전체 구조가 자연스럽게 연결됩니다.
