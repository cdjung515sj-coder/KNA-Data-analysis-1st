# 01. 기초 통계

## 1. 기술통계란?

가지고 있는 데이터를 **요약해서 특징을 파악하는 것**.

예:

- 평균이 얼마인가?
- 가장 큰 값은?
- 데이터가 몇 개인가?
- 가장 많이 나온 값은?

---

# 한눈에 보기

| 개념 | 의미 | Pandas | NumPy |
|---|---|---|---|
| 개수 | 데이터 수 | `.count()` | `len()`, `.size` |
| 합계 | 전체 합 | `.sum()` | `np.sum()` |
| 평균 | 대표적인 중심값 | `.mean()` | `np.mean()` |
| 중앙값 | 정렬했을 때 가운데 | `.median()` | `np.median()` |
| 최빈값 | 가장 자주 등장 | `.mode()` | `scipy.stats.mode()` |
| 최솟값 | 가장 작은 값 | `.min()` | `np.min()` |
| 최댓값 | 가장 큰 값 | `.max()` | `np.max()` |

---

## 2. 평균 mean

공식:

```text
평균 = 데이터 총합 / 데이터 개수
```

```python
df["온도"].mean()
```

NumPy:

```python
np.mean(data)
data.mean()
```

### 주의

이상치가 있으면 평균이 크게 영향을 받을 수 있다.

예:

```text
10 20 30 40 1000
```

1000 때문에 평균이 크게 올라간다.

---

## 3. 중앙값 median

정렬했을 때 가운데 위치하는 값.

```python
df["온도"].median()
```

NumPy:

```python
np.median(data)
```

### 언제 유용한가?

이상치가 많은 데이터에서 평균보다 대표값으로 적합할 수 있다.

---

## 4. 최빈값 mode

가장 많이 등장한 값.

```python
df["품질등급"].mode()
```

범주형 데이터에서 자주 사용.

예:

```text
정상 정상 정상 고장 고장

최빈값 = 정상
```

---

## 5. 최소 / 최대

```python
df["온도"].min()
df["온도"].max()
```

NumPy:

```python
np.min(data)
np.max(data)
```

---

## 6. 범위 Range

```text
범위 = 최댓값 - 최솟값
```

```python
df["온도"].max() - df["온도"].min()
```

### 단점

최솟값과 최댓값만 사용하므로 이상치 영향을 크게 받는다.

---

## 7. 데이터 개수

### len()

행 개수:

```python
len(df)
```

### shape

```python
df.shape
```

예:

```text
(120, 8)
```

의미:

```text
120행 × 8열
```

행 개수:

```python
df.shape[0]
```

열 개수:

```python
df.shape[1]
```

### size

전체 원소 개수:

```python
df.size
```

NumPy:

```python
arr.size
```

중요:

```python
arr.size      # O
arr.size()    # X
```

### count()

결측값을 제외한 데이터 개수:

```python
df["온도"].count()
```
