# 02. 분산 · 표준편차 · 사분위수

# 한눈에 보기

| 개념 | 의미 | Pandas |
|---|---|---|
| 분산 | 데이터가 얼마나 퍼졌나 | `.var()` |
| 표준편차 | 평균에서 얼마나 떨어졌나 | `.std()` |
| Q1 | 하위 25% 위치 | `.quantile(0.25)` |
| Q2 | 중앙값 | `.quantile(0.50)` |
| Q3 | 하위 75% 위치 | `.quantile(0.75)` |

---

# 1. 분산 Variance

데이터들이 평균에서 얼마나 떨어져 있는지를 나타낸다.

과정:

```text
데이터
 ↓
평균 계산
 ↓
각 값 - 평균
 ↓
제곱
 ↓
평균
 ↓
분산
```

Pandas:

```python
df["진동"].var()
```

NumPy:

```python
np.var(data)
```

---

# 2. 표준편차 Standard Deviation

표준편차는 분산에 제곱근을 씌운 값이다.

```text
표준편차 = √분산
```

Pandas:

```python
df["진동"].std()
```

NumPy:

```python
np.std(data)
```

---

## 표준편차 해석

표준편차가 작음:

```text
데이터가 평균 근처에 모여 있음
```

표준편차가 큼:

```text
데이터가 넓게 퍼져 있음
```

---

# 3. NumPy와 Pandas 차이

중요.

## NumPy

기본:

```python
np.var(data)
np.std(data)
```

기본값:

```text
ddof = 0
```

즉 모집단 기준.

## Pandas

```python
df["온도"].var()
df["온도"].std()
```

기본값:

```text
ddof = 1
```

즉 표본 기준.

NumPy를 Pandas와 같은 기준으로 계산하려면:

```python
np.var(data, ddof=1)
np.std(data, ddof=1)
```

---

# 4. 사분위수 Quartile

데이터를 정렬한 뒤 4등분.

```text
최소      Q1       Q2       Q3      최대
 |--------|--------|--------|--------|
 0%      25%      50%      75%     100%
```

Pandas:

```python
df["온도"].quantile(0.25)
df["온도"].quantile(0.50)
df["온도"].quantile(0.75)
```

NumPy:

```python
np.quantile(data, 0.25)
np.quantile(data, 0.50)
np.quantile(data, 0.75)
```

또는:

```python
np.percentile(data, 25)
np.percentile(data, 50)
np.percentile(data, 75)
```

---

# 핵심 암기

```python
df["온도"].var()
df["온도"].std()

Q1 = df["온도"].quantile(0.25)
Q2 = df["온도"].quantile(0.50)
Q3 = df["온도"].quantile(0.75)
```
